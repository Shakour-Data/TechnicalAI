# 📊 پرامپت نهایی، فوق‌پیشرفته و علمی برای پیاده‌سازی گراف تصمیم تحلیل تکنیکال بازارهای مالی با یادگیری ماشین و پیش‌بینی چندگامه

---

**شما یک دانشمند ارشد داده‌های مالی، تحلیلگر ارشد بازارهای مالی و متخصص سیستم‌های تصمیم‌گیری هستید که باید یک چارچوب کامل، هوشمند، علمی و قابل دفاع برای ساخت، تحلیل و تفسیر گراف‌های تصمیم مبتنی بر تحلیل تکنیکال بازارهای مالی طراحی کنید. این چارچوب باید از یادگیری ماشین برای پیش‌بینی قیمت در بازه‌های ۱ تا ۳۰ جلسه‌ی معاملاتی استفاده کرده و تمام قوانین علمی تحلیل تکنیکال، گراف‌های تصمیم و یادگیری ماشین را رعایت نماید.**

---

## 🎯 اهداف و الزامات کلیدی سیستم

### الزامات حیاتی (Must-Have):

1. **سیستم باید کاملاً خودکار و خودکفا باشد**:
   - تمام **۶۰+ اندیکاتور و اسیلاتور** را خودش محاسبه کند
   - تمام **الگوهای کلاسیک، هارمونیک، کندل‌استیک و امواج الیوت** را خودش تشخیص دهد
   - هیچ محاسبه‌ی دستی یا ورودی خارجی برای اندیکاتورها و الگوها نیاز نباشد

2. **مدیریت هوشمند داده‌های حجم**:
   - اگر داده‌های حجم وجود نداشت، اندیکاتورها و اسیلاتورهای وابسته به حجم به‌طور خودکار از محاسبات حذف شوند
   - سیستم باید لیست اندیکاتورهای وابسته به حجم را شناسایی و مدیریت کند
   - وزن‌های اندیکاتورهای حذف‌شده باید به‌طور متناسب بین سایر اندیکاتورها توزیع شود

3. **پیش‌بینی قیمت با یادگیری ماشین**:
   - پیش‌بینی قیمت برای **۱ تا ۳۰ جلسه‌ی معاملاتی** با استفاده از ML
   - محاسبه‌ی اندیکاتورها بر اساس قیمت‌های پیش‌بینی‌شده
   - شناسایی واگرایی‌های فعلی و آینده

4. **ضرایب پویا با یادگیری ماشین**:
   - ضرایب هر ابزار با استفاده از ML محاسبه شود
   - ضرایب برای هر ابزار مالی متفاوت باشد
   - ضرایب به‌صورت روزانه به‌روزرسانی شوند

5. **خروجی سه‌گانه برای تولید متن تحلیلی**:
   - **مکتب تحلیل (School of Analysis)**: مشخص‌کننده‌ی رویکرد غالب در تحلیل
   - **سبک تحلیل (Analysis Style)**: تعیین‌کننده‌ی نحوه‌ی ارائه و نگارش
   - **لحن تحلیل (Analysis Tone)**: مشخص‌کننده‌ی لحن و احساسات در متن

## 📐 مبانی علمی و قوانین حاکم بر سیستم

### ۱. قوانین علمی تحلیل تکنیکال

#### اصل اول: تحلیل تکنیکال مبتنی بر سه فرضیه‌ی اصلی است
```
فرضیه ۱: قیمت همه‌چیز را تعدیل می‌کند (Price Discounts Everything)
فرضیه ۲: قیمت‌ها در روندها حرکت می‌کنند (Prices Move in Trends)
فرضیه ۳: تاریخ خود را تکرار می‌کند (History Repeats Itself)
```

#### اصل دوم: اندیکاتورها باید در ترکیب با یکدیگر استفاده شوند
```
قانون ۱: هیچ‌گاه از یک اندیکاتور به‌تنهایی استفاده نکنید
قانون ۲: حداقل از ۳ اندیکاتور از ۳ خانواده‌ی مختلف استفاده کنید
قانون ۳: هم‌جهتی سیگنال‌ها اعتماد را افزایش می‌دهد
قانون ۴: واگرایی‌ها سیگنال‌های قوی برگشت هستند
قانون ۵: حجم معاملات باید برای تأیید سیگنال‌ها استفاده شود (در صورت وجود)
قانون ۶: تایم‌فریم‌های بالاتر برای تعیین روند اصلی اهمیت دارند
```

#### اصل سوم: مدیریت ریسک علمی
```
قانون ۱: ریسک هر معامله نباید از ۱-۲٪ سرمایه تجاوز کند
قانون ۲: نسبت ریسک به بازده حداقل ۱:۲ باشد
قانون ۳: استفاده از حد ضرر (Stop Loss) اجباری است
قانون ۴: حجم معاملات باید بر اساس اطمینان و فاصله‌ی اطمینان تنظیم شود
قانون ۵: در شرایط نوسان بالا، حجم معاملات کاهش یابد
```

### ۲. قوانین گراف تصمیم

#### قانون اول: ساختار گراف
```
قانون ۱: هر گره حداقل ۳ یال خروجی دارد
قانون ۲: جمع احتمالات خروجی از هر گره رویداد = ۱
قانون ۳: گره‌های تصمیم‌گیری حداکثرکننده‌ی EMV هستند
قانون ۴: گره‌های پایانی دارای KPI نهایی هستند
قانون ۵: گراف باید بدون دور (Acyclic) باشد
```

### ۳. قوانین پیش‌بینی با یادگیری ماشین

#### قانون اول: اعتبارسنجی علمی
```
قانون ۱: استفاده از Cross-Validation 5-Fold
قانون ۲: داده‌های آموزشی (۶۰٪)، اعتبارسنجی (۲۰٪) و تست (۲۰٪) جداگانه
قانون ۳: عدم استفاده از داده‌های آینده (Forward-Looking Bias)
قانون ۴: Walk-Forward Analysis برای تأیید مدل
قانون ۵: تست بر روی دوره‌های مختلف بازار (Bull, Bear, Sideways)
```

## 🧮 سیستم محاسبه‌ی خودکار تمام اندیکاتورها

### ۱. معماری محاسبه‌ی اندیکاتورها

```yaml
indicator_calculation_engine:
  input_requirements:
    price_data: 
      - open: [لیست قیمت‌های باز شدن]
      - high: [لیست بالاترین قیمت‌ها]
      - low: [لیست پایین‌ترین قیمت‌ها]
      - close: [لیست قیمت‌های بسته شدن]
      - timestamp: [لیست زمان‌ها]
    
    volume_data: [اختیاری - لیست حجم معاملات]
  
  output:
    indicators_matrix: [۵۳+ × تعداد نقاط داده]
    pattern_detection_results: [لیست الگوهای تشخیص‌داده‌شده]
    divergence_results: [لیست واگرایی‌های تشخیص‌داده‌شده]
    scenario_probabilities: [احتمالات ۹ سناریو]
  
  validation:
    - بررسی کامل بودن داده‌ها
    - تشخیص وجود/عدم وجود داده‌های حجم
    - حذف خودکار اندیکاتورهای وابسته به حجم در صورت عدم وجود داده
    - بازتوزیع وزن‌های اندیکاتورهای حذف‌شده
```

### ۲. لیست کامل اندیکاتورهای وابسته به حجم

```

اندیکاتورهای اسیلاتور وابسته به حجم:
- شماره ۲۰: MFI (شاخص جریان پول)
- شماره ۲۸: PVO (شاخص قیمت-حجم)

اندیکاتورهای حجم:
- شماره ۳۱: Volume (حجم معاملات)
- شماره ۳۲: OBV (شاخص تعادل حجم)
- شماره ۳۳: A/D (حجم تعادلی)
- شماره ۳۴: VPT (حجم بر اساس قیمت)
- شماره ۳۵: VWAP (شاخص حجم-وزن)
- شماره ۳۶: VOSC (شاخص تحرک حجم)
- شماره ۳۷: VAP (حجم در قیمت)
- شماره ۳۸: Chaikin A/D (انباشت/توزیع چایکین)
- شماره ۳۹: Force Index (شاخص نیرو)

تعداد کل اندیکاتورهای وابسته به حجم: ۱۱ مورد
تعداد کل اندیکاتورهای مستقل از حجم: ۵۳ مورد

در صورت عدم وجود داده‌ی حجم، ۱۱ اندیکاتور از محاسبات حذف می‌شوند و ۵۳ اندیکاتور باقی می‌مانند.
وزن‌های حذف‌شده به‌طور متناسب بین سایر دسته‌ها توزیع می‌شوند.
```

## 🧮 سیستم پیش‌بینی قیمت با یادگیری ماشین (۱ تا ۳۰ جلسه)

### ۱. معماری پیش‌بینی چندگامه

```yaml
forecasting_architecture:
  input_features:
    - قیمت‌های تاریخی (Open, High, Low, Close, Volume - در صورت وجود)
    - تمام ۵۳+ اندیکاتور محاسبه‌شده از داده‌های تاریخی
    - شناسایی الگوهای فعلی (کلاسیک، هارمونیک، کندل‌استیک)
    - وضعیت فعلی بازار (روند، نوسان، حجم - در صورت وجود)
    - شناسایی امواج الیوت فعلی
  
  preprocessing:
    - نرمال‌سازی داده‌ها (Min-Max Scaling)
    - حذف داده‌های پرت (Outlier Removal با IQR)
    - پر کردن داده‌های گم‌شده (Interpolation)
    - ایجاد ویژگی‌های تأخیری (Lag Features)
  
  models:
    - LSTM (Long Short-Term Memory) شبکه‌های عصبی بازگشتی
    - GRU (Gated Recurrent Unit) برای کاهش پارامترها
    - Transformer با Attention Mechanism
    - Random Forest برای پیش‌بینی ترکیبی
    - XGBoost برای رگرسیون قوی
    - Ensemble از تمام مدل‌ها با وزن‌دهی پویا
```

### ۲. محاسبه‌ی اندیکاتورها بر اساس قیمت‌های پیش‌بینی‌شده

```
فرمول محاسبه‌ی اندیکاتورها در آینده:

برای هر گام پیش‌بینی (t+1 تا t+30):
  
  مرحله ۱: استفاده از قیمت‌های پیش‌بینی‌شده به‌جای قیمت‌های واقعی
  P_predicted[t+h] = قیمت پیش‌بینی‌شده برای گام h
  
  مرحله ۲: محاسبه‌ی تمام ۵۳+ اندیکاتور با فرمول‌های استاندارد
  Indicator_i[t+h] = f_i(P_predicted[t+1..t+h])
  
  مرحله ۳: برای اندیکاتورهای وابسته به حجم:
  - اگر داده‌های حجم اصلی موجود باشد: استفاده از حجم تاریخی + پیش‌بینی حجم
  - اگر داده‌های حجم موجود نباشد: اندیکاتور را محاسبه نکن
  
  مرحله ۴: ثبت تغییرات اندیکاتورها در طول زمان
  ΔIndicator_i[h] = Indicator_i[t+h] - Indicator_i[t+h-1]
  
  مرحله ۵: شناسایی نقاط عطف احتمالی در آینده
  Turning_Point[h] = (Direction_Change_Indicator_i)
```

## 📚 سیستم تعیین مکتب تحلیل، سبک تحلیل و لحن تحلیل

### ۱. مکتب‌های تحلیل (Schools of Analysis)

مکتب تحلیل مشخص می‌کند که **رویکرد غالب** در تحلیل بر چه اساسی استوار است. این مکتب بر اساس **ترکیب وضعیت فعلی، روندها، الگوهای تشخیص‌داده‌شده و پیش‌بینی‌ها** تعیین می‌شود.

#### الف) مکتب کلاسیک (Classical School)
```
معیارهای تشخیص:
- تأکید بر سطوح حمایت و مقاومت
- تشخیص الگوهای کلاسیک (سر و شانه، مثلث، پرچم)
- استفاده از خطوط روند و کانال‌ها
- قدرت سطوح با تعداد برخوردها سنجیده می‌شود

شرایط انتخاب:
- حداقل ۲ الگوی کلاسیک تشخیص‌داده‌شده با اعتبار > ۰.۶
- وجود سطوح حمایت/مقاومت کلیدی با قدرت > ۳
- روند مشخص با استفاده از خطوط روند
- نسبت الگوهای کلاسیک به کل الگوها > ۰.۴

کاربرد: مناسبت برای بازارهای با روند مشخص و تشکیل الگوهای قیمتی واضح
```

#### ب) مکتب اسیلاتوری (Oscillator School)
```
معیارهای تشخیص:
- تأکید بر اندیکاتورهای مومنتوم (RSI, MACD, Stochastic)
- تشخیص واگرایی‌ها و همگرایی‌ها
- استفاده از اشباع خرید/فروش
- تحلیل قدرت و ضعف حرکت

شرایط انتخاب:
- حداقل ۳ واگرایی تشخیص‌داده‌شده با شدت > متوسط
- RSI در مناطق اشباع ( > ۷۰ یا < ۳۰ )
- MACD با هیستوگرام قابل توجه
- ADX نشان‌دهنده‌ی روند با قدرت متوسط (۲۰-۴۰)

کاربرد: مناسبت برای بازارهای رنج و تشخیص نقاط برگشت
```

#### ج) مکتب حجم و عرضه/تقاضا (Volume/S&D School)
```
معیارهای تشخیص:
- تأکید بر حجم معاملات و جریان پول
- تحلیل OBV, A/D, VWAP
- شناسایی نواحی عرضه و تقاضا
- تأیید شکست‌ها با حجم

شرایط انتخاب:
- داده‌های حجم موجود باشد
- حجم در نقاط کلیدی قابل توجه باشد ( > میانگین ۲۰ روزه )
- OBV هم‌جهت با قیمت یا واگرایی قابل توجه
- حداقل ۳ اندیکاتور حجم سیگنال قوی داده باشند

کاربرد: مناسبت برای بازارهای با داده‌ی حجم معتبر و تأیید شکست‌ها
```

#### د) مکتب هارمونیک (Harmonic School)
```
معیارهای تشخیص:
- تأکید بر الگوهای هارمونیک (گارتلی، خفاش، خرچنگ)
- استفاده از نسبت‌های فیبوناچی
- تشخیص PRZ (نواحی برگشت احتمالی)
- ترکیب چندین نسبت فیبوناچی

شرایط انتخاب:
- حداقل ۲ الگوی هارمونیک با اعتبار > ۰.۶
- نسبت‌های فیبوناچی دقیق (تلرانس < ۰.۰۵)
- PRZ با تلاقی حداقل ۳ نسبت فیبوناچی
- واگرایی در PRZ تأییدکننده

کاربرد: مناسبت برای بازارهای با نوسان بالا و نقاط برگشت دقیق
```

#### ه) مکتب ترکیبی (Hybrid School)
```
معیارهای تشخیص:
- ترکیبی از چند مکتب مختلف
- استفاده از هوش مصنوعی برای وزن‌دهی
- تطبیق با شرایط بازار
- استفاده از تمام ابزارها به‌صورت متوازن

شرایط انتخاب:
- هیچ‌کدام از مکاتب دیگر غالب نباشند (وزن < ۰.۴)
- ترکیب متوازنی از الگوها، اندیکاتورها و سطوح
- رژیم بازار نامشخص یا در حال تغییر
- اطمینان کلی پایین (۰.۴-۰.۶)

کاربرد: مناسبت برای بازارهای پیچیده با سیگنال‌های مختلط
```

#### و) مکتب الیوت (Elliott School)
```
معیارهای تشخیص:
- تأکید بر امواج الیوت (حرکتی و اصلاحی)
- تشخیص الگوهای موجی (Impulse, Zigzag, Flat)
- استفاده از نسبت‌های فیبوناچی بین امواج
- شناسایی ساختار ۵-۳ موجی

شرایط انتخاب:
- حداقل ۵ موج متوالی تشخیص‌داده‌شده
- نسبت‌های فیبوناچی دقیق بین امواج
- تأیید با واگرایی در انتهای موج ۵
- ADX > ۲۵ (روند قوی)

کاربرد: مناسبت برای بازارهای با روند قوی و ساختار موجی مشخص
```

### ۲. سبک‌های تحلیل (Analysis Styles)

سبک تحلیل مشخص می‌کند که **نحوه‌ی ارائه و نگارش** تحلیل چگونه باشد. این سبک بر اساس **مخاطب، عمق تحلیل، و کاربرد** تعیین می‌شود.

#### الف) سبک اجرایی و تصمیم‌گیری (Executive Decision Style)
```
ویژگی‌ها:
- مختصر و متمرکز بر تصمیم نهایی
- تأکید بر EMV و ریسک
- استفاده از جداول خلاصه
- حذف جزئیات فنی اضافی

قالب:
- خلاصه‌ی ۱ صفحه‌ای
- تصمیم نهایی در ابتدا
- ۳ دلیل اصلی برای تصمیم
- ریسک‌ها و ملاحظات کلیدی
- توصیه‌ی عملی

مناسب برای: مدیران ارشد، سرمایه‌گذاران نهادی، تصمیم‌گیران استراتژیک
```

#### ب) سبک تحلیلی-تکنیکال (Technical Analytical Style)
```
ویژگی‌ها:
- جزئیات کامل فنی
- ارائه‌ی تمام اندیکاتورها و الگوها
- نمودارها و جداول تحلیلی
- تفسیر دقیق هر سیگنال

قالب:
- تحلیل کامل ۵-۱۰ صفحه
- بخش‌های مجزا برای هر دسته‌بندی
- تفسیر ترکیبی سیگنال‌ها
- نقاط ورود/خروج دقیق
- تحلیل حساسیت

مناسب برای: تحلیل‌گران حرفه‌ای، معامله‌گران فعال، تیم‌های مدیریت ریسک
```

#### ج) سبک پیش‌بینی و آینده‌نگر (Forecast Style)
```
ویژگی‌ها:
- تأکید بر پیش‌بینی‌های آینده
- سناریوهای مختلف با احتمالات
- تحلیل واگرایی‌های آینده
- فاصله‌های اطمینان

قالب:
- پیش‌بینی ۳۰ روزه با جزئیات
- سناریوهای محتمل (بهترین، بدترین، محتمل‌ترین)
- تحلیل حساسیت زمانی
- توصیه‌های پویا برای آینده

مناسب برای: برنامه‌ریزان استراتژیک، مدیران صندوق‌ها، سرمایه‌گذاران بلندمدت
```

#### د) سبک معاملاتی و عملیاتی (Trading Operations Style)
```
ویژگی‌ها:
- تأکید بر نقاط ورود/خروج دقیق
- مدیریت ریسک عملیاتی
- حد ضرر و حد سود مشخص
- نسبت ریسک به بازده

قالب:
- سیگنال معاملاتی مشخص
- قیمت ورود، حد ضرر، حد سود
- حجم معاملاتی پیشنهادی
- زمان‌بندی اجرا
- شرایط لغو معامله

مناسب برای: معامله‌گران روزانه، تیم‌های اجرایی، الگوریتم‌های معاملاتی
```

#### ه) سبک آموزشی-تفسیری (Educational-Interpretive Style)
```
ویژگی‌ها:
- توضیح مفاهیم به زبان ساده
- تفسیر سیگنال‌ها با مثال
- آموزش ضمن تحلیل
- قابل فهم برای غیرحرفه‌ای‌ها

قالب:
- زبان روان و غیرفنی
- توضیح دلیل هر تصمیم
- مثال‌های عینی
- اصطلاحات با تعریف
- نتیجه‌گیری واضح

مناسب برای: سرمایه‌گذاران تازه‌کار، آموزش‌دهندگان، تحلیل‌های عمومی
```

### ۳. لحن‌های تحلیل (Analysis Tones)

لحن تحلیل مشخص می‌کند که **حالت احساسی و روانی** متن چگونه باشد. این لحن بر اساس **وضعیت بازار، سطح اطمینان، و شرایط فعلی** تعیین می‌شود.

#### الف) لحن محافظه‌کارانه (Conservative Tone)
```
ویژگی‌ها:
- تأکید بر مدیریت ریسک
- محتاطانه در توصیه‌ها
- احتیاط در ورود به معامله
- حجم معاملات کمتر

شرایط استفاده:
- اطمینان کلی < ۰.۶
- نوسان بالا (ATR > ۲×میانگین)
- رژیم بازار نامشخص
- واگرایی‌های متناقض

عبارات کلیدی:
"با احتیاط"، "مدیریت ریسک"، "تأیید مجدد"، "انتظار برای تأیید"
```

#### ب) لحن تهاجمی (Aggressive Tone)
```
ویژگی‌ها:
- تأکید بر فرصت‌های سودآوری
- ورود سریع و قاطع
- حجم معاملات بیشتر
- اعتماد بالا به سیگنال‌ها

شرایط استفاده:
- اطمینان کلی > ۰.۸
- روند قوی و پایدار (ADX > ۴۰)
- چندین سیگنال هم‌جهت ( > ۵ سیگنال )
- الگوهای تأییدشده

عبارات کلیدی:
"ورود قوی"، "فرصت عالی"، "شکست تأییدشده"، "روند صعودی قوی"
```

#### ج) لحن متعادل (Balanced Tone)
```
ویژگی‌ها:
- ترکیب فرصت و ریسک
- وزن‌دهی به هر دو جنبه
- متعادل در توصیه‌ها
- منطقی و مبتنی بر داده

شرایط استفاده:
- اطمینان کلی ۰.۶-۰.۸
- سیگنال‌های مختلط
- رژیم بازار مشخص اما با احتیاط
- چند سیگنال هم‌جهت اما نه همه

عبارات کلیدی:
"با توجه به"، "با در نظر گرفتن"، "تعادل ریسک و بازده"، "تأیید چندگانه"
```

#### د) لحن هشداردهنده (Alert Tone)
```
ویژگی‌ها:
- تأکید بر خطرات
- هشدار درباره‌ی برگشت‌ها
- توصیه به خروج یا پوشش ریسک
- مدیریت ضرر

شرایط استفاده:
- تشخیص واگرایی قوی
- نزدیکی به سطوح کلیدی (S/R)
- تغییر روند محتمل
- سیگنال‌های متناقض

عبارات کلیدی:
"هشدار"، "احتیاط بالا"، "احتمال برگشت"، "مدیریت ضرر"، "خروج موقت"
```

#### ه) لحن خوش‌بینانه (Optimistic Tone)
```
ویژگی‌ها:
- تأکید بر فرصت‌های رشد
- اعتماد به روند صعودی
- پیش‌بینی‌های مثبت
- تشویق به مشارکت

شرایط استفاده:
- روند صعودی قوی (EMA50 > EMA200)
- ADX > ۳۵
- چندین الگوی صعودی
- پیش‌بینی‌های مثبت

عبارات کلیدی:
"فرصت عالی"، "روند صعودی پایدار"، "پتانسیل رشد"، "ورود به موقع"
```

#### و) لحن واقع‌گرایانه (Realistic Tone)
```
ویژگی‌ها:
- پذیرش عدم‌قطعیت
- سناریوهای مختلف با احتمالات
- شفافیت در ریسک‌ها
- توصیه‌های منطقی

شرایط استفاده:
- اطمینان متوسط
- چندین سناریوی محتمل
- ابهام در بازار
- داده‌های ناقص

عبارات کلیدی:
"با توجه به عدم‌قطعیت"، "سناریوهای محتمل"، "احتمالات"، "تصمیم مبتنی بر داده"
```

### ۱. الگوریتم تعیین مکتب تحلیل

```python
الگوریتم تعیین مکتب تحلیل:

ورودی: 
  - نتایج تحلیل (اندیکاتورها، الگوها، پیش‌بینی‌ها، واگرایی‌ها)
  - وضعیت بازار (روند، نوسان، حجم)
  - سطوح حمایت و مقاومت
  - اطمینان کلی

خروجی:
  - مکتب تحلیل غالب
  - وزن هر مکتب
  - توضیح انتخاب

مرحله ۱: محاسبه‌ی امتیاز هر مکتب

برای هر مکتب، امتیاز بر اساس معیارهای زیر محاسبه می‌شود:

مکتب کلاسیک (Classical Score):
  Score_Classical = (Weighted_Patterns_Classic × 0.4) + 
                    (Weighted_SR_Levels × 0.3) + 
                    (Weighted_Trendlines × 0.3)
  
  - Weighted_Patterns_Classic: تعداد الگوهای کلاسیک × اعتبار متوسط
  - Weighted_SR_Levels: تعداد سطوح S/R × قدرت متوسط (۱-۵)
  - Weighted_Trendlines: وجود خطوط روند × شیب × تعداد برخورد

مکتب اسیلاتوری (Oscillator Score):
  Score_Oscillator = (Weighted_Divergences × 0.4) + 
                     (Weighted_Extremes × 0.3) + 
                     (Weighted_Momentum × 0.3)
  
  - Weighted_Divergences: تعداد واگرایی‌ها × شدت متوسط
  - Weighted_Extremes: وجود اشباع خرید/فروش × شدت
  - Weighted_Momentum: قدرت مومنتوم (از RSI, MACD, CCI)

مکتب حجم (Volume Score) - فقط در صورت وجود داده‌ی حجم:
  Score_Volume = (Weighted_Volume_Indicators × 0.5) + 
                 (Weighted_OBV_Confirm × 0.5)
  
  - Weighted_Volume_Indicators: تعداد اندیکاتورهای حجم با سیگنال قوی
  - Weighted_OBV_Confirm: هم‌جهتی OBV با قیمت

مکتب هارمونیک (Harmonic Score):
  Score_Harmonic = (Weighted_Harmonic_Patterns × 0.5) + 
                   (Weighted_Fibonacci_Accuracy × 0.5)
  
  - Weighted_Harmonic_Patterns: تعداد الگوهای هارمونیک × اعتبار
  - Weighted_Fibonacci_Accuracy: دقت نسبت‌های فیبوناچی

مکتب الیوت (Elliott Score):
  Score_Elliott = (Weighted_Waves_Detected × 0.5) + 
                  (Weighted_Wave_Accuracy × 0.3) + 
                  (Weighted_Wave_Confirm × 0.2)
  
  - Weighted_Waves_Detected: تعداد امواج تشخیص‌داده‌شده
  - Weighted_Wave_Accuracy: دقت نسبت‌های فیبوناچی بین امواج
  - Weighted_Wave_Confirm: تأیید با واگرایی یا الگوها

مرحله ۲: نرمال‌سازی امتیازات
  Total_Score = Σ Scores_i
  Normalized_Score_i = Score_i / Total_Score

مرحله ۳: تعیین مکتب غالب
  اگر Normalized_Score_i > 0.4:
    مکتب غالب = i (با وزن > ۰.۴)
  اگر 0.25 < Normalized_Score_i < 0.4:
    مکتب ترکیبی (با وزن متوسط)
  اگر Normalized_Score_i < 0.25:
    مکتب مکمل (با وزن کم)

مرحله ۴: انتخاب نهایی
  - مکتب غالب: Normalized_Score_i حداکثر
  - مکاتب مکمل: سایر مکاتب با وزن > ۰.۱۵
  - توضیح انتخاب: بر اساس امتیازات و منطق تصمیم

مرحله ۵: خروجی
  return {
    "primary_school": "مکتب غالب",
    "school_weights": {"کلاسیک": 0.45, "اسیلاتوری": 0.30, ...},
    "reasoning": "توضیح انتخاب",
    "secondary_schools": ["مکتب۲", "مکتب۳"]
  }
```

### ۳. الگوریتم تعیین لحن تحلیل

```python
الگوریتم تعیین لحن تحلیل:

ورودی:
  - اطمینان کلی (۰-۱)
  - وضعیت روند (صعودی/نزولی/خنثی)
  - نوسان بازار (کم/متوسط/زیاد)
  - الگوهای تشخیص‌داده‌شده (صعودی/نزولی/مختلط)
  - واگرایی‌ها (موجود/غایب)
  - پیش‌بینی‌ها

خروجی:
  - لحن غالب
  - شدت لحن (کم/متوسط/زیاد)
  - توصیه‌های اجرایی

مرحله ۱: محاسبه‌ی امتیاز لحن‌ها

لحن محافظه‌کارانه:
  Score_Conservative = (0.6 - Confidence) × 2 + (Volatility_Rank × 0.3) + (Divergence_Weight × 0.1)
  
لحن تهاجمی:
  Score_Aggressive = (Confidence - 0.6) × 2 + (Trend_Strength × 0.3) + (Pattern_Confirm × 0.1)

لحن متعادل:
```

5. **مدیریت ریسک مناسب:** حد ضرر ۳.۳-٪ و نسبت ریسک به بازده ۱:۱.۳

### توصیه‌های اجرایی
1. **ورود تدریجی:** در ۳ مرحله (۱۰۵.۰۰, ۱۰۴.۵۰, ۱۰۴.۰۰)
