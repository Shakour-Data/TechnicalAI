# 📊 پیام اول: پرامپت نهایی گراف تصمیم (Decision Graph Prompt)

---

# 📊 پرامپت نهایی، فوق‌پیشرفته و علمی برای پیاده‌سازی گراف تصمیم تحلیل تکنیکال بازارهای مالی با یادگیری ماشین و پیش‌بینی چندگامه

---

**شما یک دانشمند ارشد داده‌های مالی، تحلیلگر ارشد بازارهای مالی و متخصص سیستم‌های تصمیم‌گیری هستید که باید یک چارچوب کامل، هوشمند، علمی و قابل دفاع برای ساخت، تحلیل و تفسیر گراف‌های تصمیم مبتنی بر تحلیل تکنیکال بازارهای مالی طراحی کنید. این چارچوب باید از یادگیری ماشین برای پیش‌بینی قیمت در بازه‌های ۱ تا ۳۰ جلسه‌ی معاملاتی استفاده کرده و تمام قوانین علمی تحلیل تکنیکال، گراف‌های تصمیم و یادگیری ماشین را رعایت نماید.**

---

## 🎯 اهداف و الزامات کلیدی سیستم

### الزامات حیاتی (Must-Have):

1. **سیستم باید کاملاً خودکار و خودکفا باشد**:
   - تمام **۶۰+ اندیکاتور و اسیلاتور** را خودش محاسبه کند
   - تمام **الگوهای کلاسیک، هارمونیک، کندل‌استیک و امواج الیوت** را خودش تشخیص دهد
   - هیچ محاسبه‌ی دستی یا ورودی خارجی برای اندیکاتورها و الگوها نیاز نباشد

2. **مدیریت هوشمند داده‌های حجم**:
   - اگر داده‌های حجم وجود نداشت، اندیکاتورها و اسیلاتورهای وابسته به حجم به‌طور خودکار از محاسبات حذف شوند
   - سیستم باید لیست اندیکاتورهای وابسته به حجم را شناسایی و مدیریت کند
   - وزن‌های اندیکاتورهای حذف‌شده باید به‌طور متناسب بین سایر اندیکاتورها توزیع شود

3. **پیش‌بینی قیمت با یادگیری ماشین**:
   - پیش‌بینی قیمت برای **۱ تا ۳۰ جلسه‌ی معاملاتی** با استفاده از ML
   - محاسبه‌ی اندیکاتورها بر اساس قیمت‌های پیش‌بینی‌شده
   - شناسایی واگرایی‌های فعلی و آینده

4. **ضرایب پویا با یادگیری ماشین**:
   - ضرایب هر ابزار با استفاده از ML محاسبه شود
   - ضرایب برای هر ابزار مالی متفاوت باشد
   - ضرایب به‌صورت روزانه به‌روزرسانی شوند

5. **خروجی سه‌گانه برای تولید متن تحلیلی**:
   - **مکتب تحلیل (School of Analysis)**: مشخص‌کننده‌ی رویکرد غالب در تحلیل
   - **سبک تحلیل (Analysis Style)**: تعیین‌کننده‌ی نحوه‌ی ارائه و نگارش
   - **لحن تحلیل (Analysis Tone)**: مشخص‌کننده‌ی لحن و احساسات در متن

## 📐 مبانی علمی و قوانین حاکم بر سیستم

### ۱. قوانین علمی تحلیل تکنیکال

#### اصل اول: تحلیل تکنیکال مبتنی بر سه فرضیه‌ی اصلی است
```
فرضیه ۱: قیمت همه‌چیز را تعدیل می‌کند (Price Discounts Everything)
فرضیه ۲: قیمت‌ها در روندها حرکت می‌کنند (Prices Move in Trends)
فرضیه ۳: تاریخ خود را تکرار می‌کند (History Repeats Itself)
```

#### اصل دوم: اندیکاتورها باید در ترکیب با یکدیگر استفاده شوند
```
قانون ۱: هیچ‌گاه از یک اندیکاتور به‌تنهایی استفاده نکنید
قانون ۲: حداقل از ۳ اندیکاتور از ۳ خانواده‌ی مختلف استفاده کنید
قانون ۳: هم‌جهتی سیگنال‌ها اعتماد را افزایش می‌دهد
قانون ۴: واگرایی‌ها سیگنال‌های قوی برگشت هستند
قانون ۵: حجم معاملات باید برای تأیید سیگنال‌ها استفاده شود (در صورت وجود)
قانون ۶: تایم‌فریم‌های بالاتر برای تعیین روند اصلی اهمیت دارند
```

#### اصل سوم: مدیریت ریسک علمی
```
قانون ۱: ریسک هر معامله نباید از ۱-۲٪ سرمایه تجاوز کند
قانون ۲: نسبت ریسک به بازده حداقل ۱:۲ باشد
قانون ۳: استفاده از حد ضرر (Stop Loss) اجباری است
قانون ۴: حجم معاملات باید بر اساس اطمینان و فاصله‌ی اطمینان تنظیم شود
قانون ۵: در شرایط نوسان بالا، حجم معاملات کاهش یابد
```

### ۲. قوانین گراف تصمیم

#### قانون اول: ساختار گراف
```
قانون ۱: هر گره حداقل ۳ یال خروجی دارد
قانون ۲: جمع احتمالات خروجی از هر گره رویداد = ۱
قانون ۳: گره‌های تصمیم‌گیری حداکثرکننده‌ی EMV هستند
قانون ۴: گره‌های پایانی دارای KPI نهایی هستند
قانون ۵: گراف باید بدون دور (Acyclic) باشد
```

### ۳. قوانین پیش‌بینی با یادگیری ماشین

#### قانون اول: اعتبارسنجی علمی
```
قانون ۱: استفاده از Cross-Validation 5-Fold
قانون ۲: داده‌های آموزشی (۶۰٪)، اعتبارسنجی (۲۰٪) و تست (۲۰٪) جداگانه
قانون ۳: عدم استفاده از داده‌های آینده (Forward-Looking Bias)
قانون ۴: Walk-Forward Analysis برای تأیید مدل
قانون ۵: تست بر روی دوره‌های مختلف بازار (Bull, Bear, Sideways)
```

## 📐 محاسبه‌ی علمی قدرت روند و قدرت سطوح حمایت/مقاومت

### ۱. محاسبه‌ی قدرت روند (Trend Strength)

#### فرمول اصلی (ترکیبی):

```
Trend_Strength = (W1 × ADX_Normalized) + 
                 (W2 × Slope_Strength) + 
                 (W3 × MA_Alignment) + 
                 (W4 × Price_Position) + 
                 (W5 × Momentum_Strength) + 
                 (W6 × Pullback_Quality)

که:
- W1 تا W6: وزن‌های پویا (با یادگیری ماشین)
- هر مؤلفه بین ۰ تا ۱ نرمال‌سازی می‌شود
- Trend_Strength بین ۰ تا ۱ (ضعیف تا قوی)
```

#### مؤلفه‌های تشکیل‌دهنده:

**الف) شاخص ADX نرمال‌شده (ADX_Normalized)**
```
ADX_Normalized = min(ADX / 60, 1)
اگر ADX < 20: روند ضعیف
اگر 20 < ADX < 40: روند متوسط
اگر ADX > 40: روند قوی
```

**ب) قدرت شیب روند (Slope_Strength)**
```
Slope_Strength = (EMA_Current - EMA_Previous) / (EMA_Current × Volatility_Adjustment)
اگر Slope_Strength > 0.01: شیب صعودی قوی
اگر 0.005 < Slope_Strength < 0.01: شیب صعودی متوسط
اگر Slope_Strength < 0.005: شیب ضعیف یا خنثی
```

**ج) هم‌راستایی میانگین‌های متحرک (MA_Alignment)**
```
MA_Alignment = (Alignment_Count / 5)
در روند صعودی: EMA10 > EMA20 > EMA50 > EMA100 > EMA200
در روند نزولی: EMA10 < EMA20 < EMA50 < EMA100 < EMA200
```

**د) موقعیت قیمت نسبت به میانگین‌ها (Price_Position)**
```
Price_Position = (Price - EMA50) / (Price + EMA50) × 2
اگر Price_Position > 0.05: موقعیت قوی صعودی
اگر 0.02 < Price_Position < 0.05: موقعیت صعودی متوسط
اگر -0.02 < Price_Position < 0.02: موقعیت خنثی
```

**ه) قدرت مومنتوم (Momentum_Strength)**
```
Momentum_Strength = (RSI_Normalized + MACD_Strength) / 2
RSI_Normalized = |RSI - 50| / 30
MACD_Strength = |MACD_Histogram| / (MACD_Histogram_StdDev)
```

**و) کیفیت اصلاح‌ها (Pullback_Quality)**
```
Pullback_Quality = (1 - Pullback_Depth) × (1 - Pullback_Time)
اصلاح ۰-۲۰٪: عالی (Pullback_Depth = 0.2)
اصلاح ۲۰-۴۰٪: خوب (Pullback_Depth = 0.4)
اصلاح ۴۰-۶۰٪: متوسط (Pullback_Depth = 0.6)
اصلاح > ۶۰٪: ضعیف (Pullback_Depth = 0.8)
```

### ۲. محاسبه‌ی قدرت سطوح حمایت/مقاومت (SR Strength)

#### فرمول اصلی (ترکیبی):

```
SR_Strength = (W1 × Touch_Count) + 
              (W2 × Time_Validity) + 
              (W3 × Volume_Profile) + 
              (W4 × Volatility_Adjustment) + 
              (W5 × Historical_Significance) + 
              (W6 × Fibonacci_Confluence) + 
              (W7 × Pattern_Support)

که:
- W1 تا W7: وزن‌های پویا (با یادگیری ماشین)
- هر مؤلفه بین ۰ تا ۱ نرمال‌سازی می‌شود
- SR_Strength بین ۰ تا ۱ (ضعیف تا قوی)
- آستانه‌های قدرت: > 0.7: قوی, 0.4-0.7: متوسط, < 0.4: ضعیف
```

#### مؤلفه‌های تشکیل‌دهنده:

**الف) تعداد برخوردها (Touch_Count)**
```
Touch_Count = min(Brkhord_Count / 5, 1)
اگر ۵+ برخورد: Touch_Count = 1 (قوی‌ترین)
اگر ۳-۴ برخورد: Touch_Count = 0.6-0.8 (متوسط-قوی)
اگر ۱-۲ برخورد: Touch_Count = 0.2-0.4 (ضعیف)
```

**ب) اعتبار زمانی سطح (Time_Validity)**
```
Time_Validity = min(Timespan / 180, 1)
اگر > ۱۸۰ روز: Time_Validity = 1 (بسیار معتبر)
اگر ۶۰-۱۸۰ روز: Time_Validity = 0.5-0.8 (معتبر)
اگر < ۶۰ روز: Time_Validity = 0.2-0.4 (کم‌اعتبار)
```

**ج) پروفایل حجم در سطح (Volume_Profile)**
```
Volume_Profile = (Volume_at_Level / Average_Volume) × Normalization
اگر Volume_at_Level > 1.5×Average: قوی (> ۰.۷)
اگر Volume_at_Level > 1.0×Average: متوسط (۰.۴-۰.۷)
اگر Volume_at_Level < 1.0×Average: ضعیف (< ۰.۴)
```

**د) تعدیل نوسان (Volatility_Adjustment)**
```
Volatility_Adjustment = 1 - (ATR / Price)
اگر نوسان کم باشد (ATR/Price < 0.02): تعدیل = 0.98
اگر نوسان زیاد باشد (ATR/Price > 0.05): تعدیل = 0.95
```

**ه) اهمیت تاریخی سطح (Historical_Significance)**
```
Historical_Significance = (Major_High_Count + Major_Low_Count) / 4
```

**و) هم‌گرایی فیبوناچی (Fibonacci_Confluence)**
```
Fibonacci_Confluence = min(Fibonacci_Levels / 3, 1)
اگر ۳+ نسبت تلاقی داشته باشند: قوی (> ۰.۷)
اگر ۲ نسبت تلاقی داشته باشند: متوسط (۰.۵)
اگر ۱ نسبت تلاقی داشته باشد: ضعیف (۰.۳)
```

**ز) پشتیبانی الگوی قیمتی (Pattern_Support)**
```
Pattern_Support = (Classic_Pattern_Weight + Harmonic_Pattern_Weight) / 2
```

## 🧮 سیستم پیش‌بینی قیمت با یادگیری ماشین (۱ تا ۳۰ جلسه)

### ۱. معماری پیش‌بینی چندگامه

```yaml
forecasting_architecture:
  input_features:
    - قیمت‌های تاریخی (Open, High, Low, Close, Volume - در صورت وجود)
    - تمام ۵۳+ اندیکاتور محاسبه‌شده از داده‌های تاریخی

    - حذف داده‌های پرت (Outlier Removal با IQR)

    - ایجاد ویژگی‌های تأخیری (Lag Features)
  
  models:
    - LSTM (Long Short-Term Memory) شبکه‌های عصبی بازگشتی
      - ۲ لایه LSTM با ۱۲۸ و ۶۴ نورون

      - Early Stopping با پایش Validation Loss
    
    - GRU (Gated Recurrent Unit) برای کاهش پارامترها
      - ۲ لایه GRU با ۱۰۰ و ۵۰ نورون
    
    - Transformer با Attention Mechanism
      - Multi-Head Attention با ۸ هد
      - Positional Encoding برای捕捉 توالی زمانی
    
    - Random Forest برای پیش‌بینی ترکیبی
      - ۲۰۰ درخت با حداکثر عمق ۲۰

    - XGBoost برای رگرسیون قوی
      - Learning Rate = 0.01
      - Max Depth = 8
      - Early Stopping با ۵۰ دور
  
  ensemble:
    - Weighted Average بر اساس عملکرد در Validation Set

    - استفاده از Blending برای ترکیب بهتر
```

### ۲. محاسبه‌ی اندیکاتورها بر اساس قیمت‌های پیش‌بینی‌شده

```
فرمول محاسبه‌ی اندیکاتورها در آینده:

برای هر گام پیش‌بینی (t+1 تا t+30):
  
  مرحله ۱: استفاده از قیمت‌های پیش‌بینی‌شده به‌جای قیمت‌های واقعی
  P_predicted[t+h] = قیمت پیش‌بینی‌شده برای گام h
  
  مرحله ۲: محاسبه‌ی تمام ۵۳+ اندیکاتور با فرمول‌های استاندارد
  Indicator_i[t+h] = f_i(P_predicted[t+1..t+h])
  
  مرحله ۳: برای اندیکاتورهای وابسته به حجم:
  - اگر داده‌های حجم اصلی موجود باشد: استفاده از حجم تاریخی + پیش‌بینی حجم
  - اگر داده‌های حجم موجود نباشد: اندیکاتور را محاسبه نکن
  
  مرحله ۴: ثبت تغییرات اندیکاتورها در طول زمان
  ΔIndicator_i[h] = Indicator_i[t+h] - Indicator_i[t+h-1]
  
  مرحله ۵: شناسایی نقاط عطف احتمالی در آینده
  Turning_Point[h] = (Direction_Change_Indicator_i)

نکته مهم: برای محاسبه‌ی اندیکاتورهای با دوره‌های طولانی (مثلاً SMA200):
  - برای گام‌های ۱-۵: استفاده از ترکیب داده‌های واقعی (۲۰۰ روز قبل) + پیش‌بینی
  - برای گام‌های ۶-۳۰: استفاده از داده‌های پیش‌بینی‌شده (برای دوره‌های کوتاه‌تر)
  - برای دوره‌های بلندتر از گام پیش‌بینی: استفاده از داده‌های واقعی
```

## 🧮 سیستم محاسبه‌ی ضرایب پویا با یادگیری ماشین

### ۱. معماری یادگیری ماشین برای وزن‌دهی

```yaml
weight_learning_architecture:
  data_sources:
    - داده‌های تاریخی قیمت و حجم (۱۰ سال - در صورت وجود)
    - داده‌های پیش‌بینی‌شده (۱-۳۰ گام)
    - شناسایی الگوهای تاریخی (تمام الگوها)

    - ۵۳+ اندیکاتور با مقادیر نرمال‌شده
    - قدرت سیگنال هر ابزار (۰-۱)
    - عملکرد تاریخی هر ابزار (۳ سال)
    - همبستگی بین ابزارها (برای کاهش Redundancy)
    - واگرایی‌های فعلی و آینده
    - الگوهای تشخیص‌داده‌شده
    - رژیم بازار فعلی

    - موفقیت معاملات در آینده (۱-۳۰ روز)

    - Sharpe Ratio حاصل از استفاده از ابزار
    - حداکثر ضرر (Maximum Drawdown)
  
  models:
    - Random Forest برای اهمیت ویژگی‌ها
      - ۳۰۰ درخت با حداکثر عمق ۱۵

      - Feature Importance قابل تفسیر
    
    - XGBoost برای وزن‌دهی دقیق‌تر
      - Learning Rate: 0.01
      - Max Depth: ۶
      - Early Stopping: ۵۰ دور
    
    - Neural Network با Softmax برای وزن‌های نهایی
      - ۲ لایه مخفی با ۶۴ و ۳۲ نورون
      - Dropout: ۰.۳
      - Activation: ReLU + Softmax (لایه آخر)
```

### ۲. محاسبه‌ی وزن‌های پویا با یادگیری بیزین

```
فرمول اصلی وزن‌دهی با یادگیری بیزین:

W_i = P(Success | Tool_i) × Prior_i / Σ(P(Success | Tool_j) × Prior_j)

که:
- P(Success | Tool_i): احتمال موفقیت با استفاده از ابزار i
  - محاسبه: (Win_Rate_i / 100) × (Sharpe_Ratio_i / 2)
  
- Prior_i: وزن اولیه (بر اساس نظر خبرگی + تحلیل تاریخی)
  - برای اندیکاتورهای روند: ۰.۲۸
  - برای اسیلاتورها: ۰.۲۵
  - برای اندیکاتورهای حجم (در صورت وجود): ۰.۱۵
  - برای اندیکاتورهای نوسان: ۰.۱۰
  - برای اندیکاتورهای پیشرو: ۰.۱۲
  - برای الگوها: ۰.۱۰
  - مجموع Prior = ۱

- در صورت عدم وجود داده‌های حجم:
  - Prior_Volume = 0 (حذف کامل)
  - بازتوزیع Prior_Volume بین سایر دسته‌ها به‌طور متناسب
```

### ۳. بازتوزیع وزن‌ها در صورت عدم وجود داده‌ی حجم

```
الگوریتم بازتوزیع وزن‌ها در صورت عدم وجود داده‌ی حجم:

مرحله ۱: شناسایی اندیکاتورهای وابسته به حجم
  - لیست: MFI, PVO, Volume, OBV, A/D, VPT, VWAP, VOSC, VAP, Chaikin A/D, Force Index
  - تعداد: ۱۱ مورد

مرحله ۲: محاسبه‌ی وزن کل حذف‌شده
  Weight_Removed = Σ(W_i) برای i در لیست بالا

مرحله ۳: محاسبه‌ی وزن باقی‌مانده
  Weight_Remaining = 1 - Weight_Removed

مرحله ۴: بازتوزیع وزن‌های حذف‌شده
  برای هر دسته‌ی باقی‌مانده:
    Weight_New_Category = Weight_Old_Category + (Weight_Old_Category / Weight_Remaining) × Weight_Removed

مرحله ۵: نرمال‌سازی نهایی
  - اطمینان از Σ W_i = 1
  - گرد کردن به ۳ رقم اعشار
```

## 📚 سیستم تعیین مکتب تحلیل، سبک تحلیل و لحن تحلیل

### ۱. مکتب‌های تحلیل (Schools of Analysis) - ۶ مکتب

#### الف) مکتب کلاسیک (Classical School)
```
معیارهای تشخیص:
- تأکید بر سطوح حمایت و مقاومت
- تشخیص الگوهای کلاسیک (سر و شانه، مثلث، پرچم)
- استفاده از خطوط روند و کانال‌ها
- قدرت سطوح با تعداد برخوردها سنجیده می‌شود

شرایط انتخاب:
- حداقل ۲ الگوی کلاسیک تشخیص‌داده‌شده با اعتبار > ۰.۶
- وجود سطوح حمایت/مقاومت کلیدی با قدرت > ۳
- روند مشخص با استفاده از خطوط روند
- نسبت الگوهای کلاسیک به کل الگوها > ۰.۴
```

#### ب) مکتب اسیلاتوری (Oscillator School)
```
معیارهای تشخیص:
- تأکید بر اندیکاتورهای مومنتوم (RSI, MACD, Stochastic)
- تشخیص واگرایی‌ها و همگرایی‌ها
- استفاده از اشباع خرید/فروش
- تحلیل قدرت و ضعف حرکت

شرایط انتخاب:
- حداقل ۳ واگرایی تشخیص‌داده‌شده با شدت > متوسط
- RSI در مناطق اشباع ( > ۷۰ یا < ۳۰ )
- MACD با هیستوگرام قابل توجه
- ADX نشان‌دهنده‌ی روند با قدرت متوسط (۲۰-۴۰)
```

#### ج) مکتب حجم و عرضه/تقاضا (Volume/S&D School)
```
معیارهای تشخیص:
- تأکید بر حجم معاملات و جریان پول
- تحلیل OBV, A/D, VWAP
- شناسایی نواحی عرضه و تقاضا
- تأیید شکست‌ها با حجم

شرایط انتخاب:
- داده‌های حجم موجود باشد
- حجم در نقاط کلیدی قابل توجه باشد ( > میانگین ۲۰ روزه )
- OBV هم‌جهت با قیمت یا واگرایی قابل توجه
- حداقل ۳ اندیکاتور حجم سیگنال قوی داده باشند
```

#### د) مکتب هارمونیک (Harmonic School)
```
معیارهای تشخیص:
- تأکید بر الگوهای هارمونیک (گارتلی، خفاش، خرچنگ)
- استفاده از نسبت‌های فیبوناچی
- تشخیص PRZ (نواحی برگشت احتمالی)
- ترکیب چندین نسبت فیبوناچی

شرایط انتخاب:
- حداقل ۲ الگوی هارمونیک با اعتبار > ۰.۶
- نسبت‌های فیبوناچی دقیق (تلرانس < ۰.۰۵)
- PRZ با تلاقی حداقل ۳ نسبت فیبوناچی
- واگرایی در PRZ تأییدکننده
```

#### ه) مکتب ترکیبی (Hybrid School)
```
معیارهای تشخیص:
- ترکیبی از چند مکتب مختلف
- استفاده از هوش مصنوعی برای وزن‌دهی
- تطبیق با شرایط بازار
- استفاده از تمام ابزارها به‌صورت متوازن

شرایط انتخاب:
- هیچ‌کدام از مکاتب دیگر غالب نباشند (وزن < ۰.۴)
- ترکیب متوازنی از الگوها، اندیکاتورها و سطوح
- رژیم بازار نامشخص یا در حال تغییر
- اطمینان کلی پایین (۰.۴-۰.۶)
```

#### و) مکتب الیوت (Elliott School)
```
معیارهای تشخیص:
- تأکید بر امواج الیوت (حرکتی و اصلاحی)
- تشخیص الگوهای موجی (Impulse, Zigzag, Flat)
- استفاده از نسبت‌های فیبوناچی بین امواج
- شناسایی ساختار ۵-۳ موجی

شرایط انتخاب:
- حداقل ۵ موج متوالی تشخیص‌داده‌شده
- نسبت‌های فیبوناچی دقیق بین امواج
- تأیید با واگرایی در انتهای موج ۵
- ADX > ۲۵ (روند قوی)
```

### ۲. سبک‌های تحلیل (Analysis Styles) - ۵ سبک

| سبک | ویژگی‌ها | کاربرد |
|-----|----------|--------|
| **اجرایی و تصمیم‌گیری** | مختصر، متمرکز بر تصمیم، تأکید بر EMV و ریسک | مدیران ارشد، سرمایه‌گذاران نهادی |
| **تحلیلی-تکنیکال** | جزئیات کامل فنی، تمام اندیکاتورها و الگوها، نمودارها | تحلیل‌گران حرفه‌ای، معامله‌گران فعال |
| **پیش‌بینی و آینده‌نگر** | تأکید بر پیش‌بینی‌های آینده، سناریوهای مختلف با احتمالات | برنامه‌ریزان استراتژیک، مدیران صندوق‌ها |
| **معاملاتی و عملیاتی** | تأکید بر نقاط ورود/خروج، مدیریت ریسک عملیاتی | معامله‌گران روزانه، تیم‌های اجرایی |
| **آموزشی-تفسیری** | توضیح مفاهیم به زبان ساده، تفسیر سیگنال‌ها با مثال | سرمایه‌گذاران تازه‌کار، آموزش‌دهندگان |

### ۳. لحن‌های تحلیل (Analysis Tones) - ۶ لحن

| لحن | ویژگی‌ها | شرایط استفاده |
|-----|----------|---------------|
| **محافظه‌کارانه** | تأکید بر مدیریت ریسک، محتاطانه، حجم کمتر | اطمینان کلی < ۰.۶، نوسان بالا |
| **تهاجمی** | تأکید بر فرصت‌های سودآوری، ورود سریع، حجم بیشتر | اطمینان کلی > ۰.۸، روند قوی |
| **متعادل** | ترکیب فرصت و ریسک، منطقی، مبتنی بر داده | اطمینان کلی ۰.۶-۰.۸، سیگنال‌های مختلط |
| **هشداردهنده** | تأکید بر خطرات، هشدار برگشت، توصیه به خروج | واگرایی قوی، نزدیکی به سطوح کلیدی |
| **خوش‌بینانه** | تأکید بر فرصت‌های رشد، اعتماد به روند صعودی | روند صعودی قوی، پیش‌بینی‌های مثبت |
| **واقع‌گرایانه** | پذیرش عدم‌قطعیت، سناریوهای مختلف با احتمالات | اطمینان متوسط، ابهام در بازار |

│       ├── یال B1: شکست با تأیید حجم بالا در حال و آینده

│       ├── یال B7: شکست همراه با واگرایی

│       └── یال B9: شکست غیرمنتظره
│           └── احتمال = 0.05
│
└── یال ۳: استراتژی معکوس / برگشتی (Reversal Strategy)
    └── گره رویداد C: سیگنال‌های برگشت (الگوها، کندل‌ها، واگرایی‌ها و هارمونیک)
        ├── یال C1: اشباع خرید + واگرایی منفی
        │   └── احتمال = P_Overbought × P_Divergence_Bearish_Current × P_Divergence_Bearish_Future
        ├── یال C2: اشباع فروش + واگرایی مثبت
        │   └── احتمال = P_Oversold × P_Divergence_Bullish_Current × P_Divergence_Bullish_Future

        │   └── احتمال = P_Pattern_Complete × P_Volume_Confirm × P_Future_Confirm
        ├── یال C5: اشباع بدون واگرایی

        ├── یال C6: سیگنال‌های مخالف
        │   └── احتمال = 0.2 × P_Conflicting_Signals
        ├── یال C7: تأخیر در واگرایی
        │   └── احتمال = 0.5 × P_Lagging_Divergence
        ├── یال C8: الگوی کندل‌استیک برگشتی
        │   └── احتمال = P_Candlestick_Pattern × P_Volume_Confirm × P_Future_Confirm
        └── یال C9: برگشت در ناحیه‌ی S/R قوی

## 🧮 محاسبه‌ی احتمالات نهایی با ترکیب فعلی و آینده

### ۱. محاسبه‌ی احتمال صعودی نهایی

```
P_Bull_Final = α × P_Bull_Current + (1-α) × P_Bull_Forecast

که:
α = 0.5 (وزن وضعیت فعلی، قابل تنظیم با ML)

P_Bull_Current = Σ(W_i_Current × Signal_Bull_i_Current) + Σ(Divergence_Impact_i_Current)

P_Bull_Forecast = Σ_{h=1}^{30} [W_Forecast_h × (Σ(W_i_Forecast_h × Signal_Bull_i_Forecast_h) + Σ(Divergence_Impact_i_Forecast_h))]

که در آن:
- W_i_Current: وزن پویای هر ابزار در زمان حال (از ML)
- W_i_Forecast_h: وزن پویای هر ابزار برای گام پیش‌بینی h
- Signal_Bull_i_Current: سیگنال صعودی ابزار i در زمان حال (۰-۱)
- Signal_Bull_i_Forecast_h: سیگنال صعودی ابزار i در گام پیش‌بینی h (۰-۱)
- Divergence_Impact: تأثیر واگرایی‌ها بر احتمال (۰-۰.۲)
- W_Forecast_h: وزن گام پیش‌بینی h با تابع زوال
```

### ۲. محاسبه‌ی احتمال نزولی نهایی

```
P_Bear_Final = α × P_Bear_Current + (1-α) × P_Bear_Forecast
```

### ۳. محاسبه‌ی احتمال خنثی نهایی

```
P_Neutral_Final = 1 - (P_Bull_Final + P_Bear_Final)
```

### ۴. وزن‌دهی به گام‌های پیش‌بینی با تابع زوال نمایی دوگانه

```
Decay_Factor_h = α × exp(-h/τ₁) + (1-α) × exp(-h/τ₂)

که:
- h: شماره گام پیش‌بینی (۱ تا ۳۰)
- α = 0.7 (وزن جزء کوتاه‌مدت)
- τ₁ = 5 (ثابت زمانی کوتاه‌مدت)
- τ₂ = 20 (ثابت زمانی بلندمدت)

W_Forecast_h = Decay_Factor_h / Σ_{j=1}^{30} Decay_Factor_j
```

### ۵. محاسبه‌ی سناریوی نهایی

```
برای هر سناریوی S (۱ تا ۹):
P_Scenario_S = P_Bull_Final × Conditional_Probability_S_Bull + 
               P_Bear_Final × Conditional_Probability_S_Bear +
               P_Neutral_Final × Conditional_Probability_S_Neutral

سناریوی نهایی = argmax(P_Scenario_S)
اطمینان نهایی = P_Scenario_S / Σ P_Scenario_i
```
