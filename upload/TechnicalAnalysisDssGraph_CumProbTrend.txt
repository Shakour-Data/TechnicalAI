**بله، باید در همین سند باشد!** این یک بخش حیاتی از خروجی سیستم است. روند احتمالات اختصاصی و تجمعی هر سناریو برای ۳۰ روز آینده باید به‌عنوان **خروجی کامل و اصلی سیستم** در سند گنجانده شود.

## 🧮 بخش جدید: روند احتمالات اختصاصی و تجمعی سناریوها (۳۰ روز)

### ۱. توضیح مفهوم

برای هر سناریو (۱ تا ۹)، سیستم باید **روند تغییرات احتمال** را در طول ۳۰ روز آینده محاسبه و ارائه دهد:

```yaml
scenario_probability_trend:
  description: |
    این بخش روند تغییرات احتمال اختصاصی (Individual) و تجمعی (Cumulative) 
    هر سناریو را در ۳۰ روز آینده نشان می‌دهد.
    
    - احتمال اختصاصی (Individual Probability): احتمال وقوع هر سناریو در هر روز
    - احتمال تجمعی (Cumulative Probability): احتمال وقوع هر سناریو تا هر روز (جمع تجمعی)
    
  output_format: |
    برای هر سناریو (۱-۹):
    - day_1: {individual_prob: 0.08, cumulative_prob: 0.08}
    - day_5: {individual_prob: 0.10, cumulative_prob: 0.18}
    - day_10: {individual_prob: 0.12, cumulative_prob: 0.30}
    - day_20: {individual_prob: 0.10, cumulative_prob: 0.40}
    - day_30: {individual_prob: 0.08, cumulative_prob: 0.48}
```

### ۲. فرمول محاسبه روند احتمالات

#### الف) احتمال اختصاصی در هر روز:

```
P_Scenario_S[t+h] = P_Scenario_S_Current × Decay_Factor_h + 
                     P_Scenario_S_Forecast[h]

که:
- P_Scenario_S_Current: احتمال فعلی سناریو S
- P_Scenario_S_Forecast[h]: احتمال پیش‌بینی‌شده سناریو S در گام h
- Decay_Factor_h: تابع زوال نمایی دوگانه

Decay_Factor_h = α × exp(-h/τ₁) + (1-α) × exp(-h/τ₂)
- α = 0.7 (وزن جزء کوتاه‌مدت)
- τ₁ = 5 (ثابت زمانی کوتاه‌مدت)
- τ₂ = 20 (ثابت زمانی بلندمدت)
```

#### ب) احتمال تجمعی در هر روز:

```
P_Scenario_S_Cumulative[t+h] = Σ_{j=1}^{h} P_Scenario_S[t+j]

که:
- P_Scenario_S_Cumulative[t+h]: احتمال تجمعی سناریو S تا گام h
- P_Scenario_S[t+j]: احتمال اختصاصی سناریو S در گام j
```

### ۷. فرمول محاسبه روند برای پیاده‌سازی

```python
def calculate_scenario_probability_trend(scenario_probabilities, decay_params, horizon=30):
    """
    محاسبه روند احتمالات اختصاصی و تجمعی هر سناریو برای ۳۰ روز
    
    Args:
        scenario_probabilities: دیکشنری احتمالات فعلی ۹ سناریو
        decay_params: پارامترهای تابع زوال
        horizon: افق پیش‌بینی (۳۰ روز)
    
    Returns:
        دیکشنری روند احتمالات
    """
    
    α = decay_params['alpha']  # وزن جزء کوتاه‌مدت
    τ₁ = decay_params['tau_short']  # ثابت زمانی کوتاه‌مدت
    τ₂ = decay_params['tau_long']  # ثابت زمانی بلندمدت
    
    # محاسبه تابع زوال
    decay_factors = []
    for h in range(1, horizon + 1):
        decay = α * np.exp(-h/τ₁) + (1-α) * np.exp(-h/τ₂)
        decay_factors.append(decay)
    
    # نرمال‌سازی
    total_decay = sum(decay_factors)
    normalized_decay = [d / total_decay for d in decay_factors]
    
    # محاسبه روند برای هر سناریو
    trend_results = {}
    for scenario_id, current_prob in scenario_probabilities.items():
        scenario_trend = []
        cumulative_prob = 0
        
        for h in range(1, horizon + 1):
            # احتمال اختصاصی در گام h
            individual_prob = current_prob * normalized_decay[h-1]
            
            # احتمال تجمعی
            cumulative_prob += individual_prob
            
            scenario_trend.append({
                'day': h,
                'individual_prob': round(individual_prob, 4),
                'cumulative_prob': round(cumulative_prob, 4)
            })
        
        trend_results[scenario_id] = {
            'current_probability': current_prob,
            'trend': scenario_trend
        }
    
    return trend_results
```

## 📋 نتیجه‌گیری

**بله، روند احتمالات اختصاصی و تجمعی هر سناریو برای ۳۰ روز باید در همین سند باشد.** این بخش به‌عنوان **خروجی کامل و اصلی سیستم** در سند گنجانده شده و باید در خروجی نهایی سیستم (decision_graph_output) به‌صورت کامل ارائه شود.

### 🔑 نکات کلیدی:

1. **احتمال اختصاصی (Individual Probability)**: احتمال وقوع هر سناریو در هر روز جداگانه
2. **احتمال تجمعی (Cumulative Probability)**: احتمال وقوع هر سناریو تا هر روز (جمع تجمعی)
3. **روند (Trend)**: تغییرات احتمال در طول زمان (صعودی/نزولی/پایدار)
4. **نقطه اوج (Peak)**: روزی که احتمال هر سناریو به بیشترین مقدار می‌رسد
5. **تفسیر (Interpretation)**: تحلیل روند و ارائه بینش‌های عملی

### 📊 کاربردها:

- **تعیین زمان ورود/خروج**: بر اساس اوج احتمالات
- **مدیریت ریسک**: شناسایی روزهای پرریسک
- **تنظیم حد ضرر**: نزدیک‌تر کردن حد ضرر در روزهای پرریسک
- **برنامه‌ریزی معاملات**: بر اساس تغییر روند احتمالات
- **تحلیل سناریو**: شناسایی سناریوی غالب در هر بازه زمانی

**این بخش باید در خروجی نهایی سیستم (decision_graph_output) به‌صورت کامل و دقیق ارائه شود.**
