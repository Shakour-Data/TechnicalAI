# 📊 سند بازنویسی‌شده: روند احتمالات اختصاصی و تجمعی سناریوها (نسخه اصلاح‌شده برای هوش مصنوعی)

> **توجه:** این سند بر اساس بازبینی اصول آماری و اصلاح مفاهیم «احتمال تجمعی» و «روند احتمالات» بازنویسی شده است. هدف، ارائه دستورالعملی شفاف و بدون ابهام برای پیاده‌سازی توسط هوش مصنوعی است.

## ۱. معرفی کلی

این سند مشخص می‌کند که **احتمال اختصاصی (Individual Probability)** و **احتمال تجمعی (Cumulative Probability)** برای هر یک از ۹ سناریوی سیستم گراف تصمیم، در هر روز چگونه محاسبه و گزارش می‌شوند. همچنین، **روند تغییرات این احتمالات در ۳۰ روز گذشته** به‌صورت جدول زمانی ارائه می‌شود.

**اصول بنیادین:**

1. احتمال تجمعی فقط در **یک روز مشخص** تعریف می‌شود و **جمع احتمالات روزهای مختلف** (به‌عنوان مثال جمع احتمال سناریو در روز ۱ و روز ۲) **غیرمجاز** است.
2. برای محاسبه احتمالات در هر روز تاریخی، **فقط از داده‌های موجود تا انتهای همان روز** استفاده می‌شود (اصل عدم نگاه به آینده – No Look‑ahead Bias).
3. هیچ فرمول مصنوعی (مانند Decay Factor) برای تولید روند احتمالات استفاده نمی‌شود؛ روند مستقیماً از مقادیر واقعی محاسبه‌شده در هر روز استخراج می‌گردد.

## ۲. تعریف سناریوها

سیستم دارای ۹ سناریو است که در سه دسته قرار می‌گیرند:

| دسته | سناریوها (به ترتیب شدت از شدید به خفیف) |
|------|-------------------------------------------|
| صعودی (Bullish) | ۱. شوک صعودی (Shock Up) <br> ۲. صعودی شتاب‌دار (Accelerated Bullish) <br> ۳. صعودی قوی (Strong Bullish) <br> ۴. صعودی خفیف (Weak Bullish) |
| خنثی (Neutral) | ۵. رنج (Range) |
| نزولی (Bearish) | ۹. شوک نزولی (Shock Down) <br> ۸. نزولی شتاب‌دار (Accelerated Bearish) <br> ۷. نزولی قوی (Strong Bearish) <br> ۶. نزولی خفیف (Weak Bearish) |

**ترتیب پله‌ای:** در هر دسته، سناریوها از **شدیدترین** به **خفیف‌ترین** مرتب می‌شوند. احتمال تجمعی هر سناریو، مجموع احتمال اختصاصی آن سناریو و تمام سناریوهای **شدیدتر از آن** در همان دسته است.

---

## ۳. احتمال اختصاصی (Individual Probability)

**تعریف:** احتمال اختصاصی هر سناریو در یک روز مشخص، احتمال وقوع همان سناریو در آن روز است (بدون دخالت سناریوهای دیگر). مقدار آن عددی بین ۰ و ۱ است.

**شرط نرمال‌سازی:** در هر روز، مجموع احتمال اختصاصی تمام ۹ سناریو باید برابر با ۱ باشد:

```
P_ind(shock_up) + P_ind(accel_bull) + ... + P_ind(shock_down) = 1
```

**روش محاسبه:** احتمال اختصاصی هر سناریو از خروجی مدل‌های یادگیری ماشین (مانند Random Forest، XGBoost، Neural Network و ...) به دست می‌آید و سپس نرمال می‌شود.

---

## ۴. احتمال تجمعی (Cumulative Probability)

**تعریف:** احتمال تجمعی یک سناریو در یک روز مشخص، **جمع احتمال اختصاصی همان سناریو و تمام سناریوهای شدیدتر از آن در همان دسته** است. این جمع‌کردن **فقط در همان روز** انجام می‌شود و **بین روزها هیچ جمعی وجود ندارد**.

### ۴.۱ فرمول‌های محاسبه احتمال تجمعی در روز t

**دسته صعودی (Bullish):**

```
Cum(shock_up)    = P_ind(shock_up)
Cum(accel_bull)  = P_ind(shock_up) + P_ind(accel_bull)
Cum(strong_bull) = P_ind(shock_up) + P_ind(accel_bull) + P_ind(strong_bull)
Cum(weak_bull)   = P_ind(shock_up) + P_ind(accel_bull) + P_ind(strong_bull) + P_ind(weak_bull)
```

**دسته خنثی (Neutral):**

```
Cum(range) = P_ind(range)
```

**دسته نزولی (Bearish):**

```
Cum(shock_down)  = P_ind(shock_down)
Cum(accel_bear)  = P_ind(shock_down) + P_ind(accel_bear)
Cum(strong_bear) = P_ind(shock_down) + P_ind(accel_bear) + P_ind(strong_bear)
Cum(weak_bear)   = P_ind(shock_down) + P_ind(accel_bear) + P_ind(strong_bear) + P_ind(weak_bear)
```

**مثال عددی (برای یک روز):**

فرض کنید احتمال اختصاصی در روز t به این صورت است (جمع = ۱):

| سناریو | احتمال اختصاصی (P_ind) |
|--------|------------------------|
| شوک صعودی | ۰.۰۸ |
| صعودی شتاب‌دار | ۰.۱۵ |
| صعودی قوی | ۰.۲۸ |
| صعودی خفیف | ۰.۱۲ |
| رنج | ۰.۱۵ |
| نزولی خفیف | ۰.۰۸ |
| نزولی قوی | ۰.۰۸ |
| نزولی شتاب‌دار | ۰.۰۴ |
| شوک نزولی | ۰.۰۲ |

**محاسبه احتمال تجمعی:**

- صعودی:
  - Cum(shock_up) = ۰.۰۸
  - Cum(accel_bull) = ۰.۰۸ + ۰.۱۵ = ۰.۲۳
  - Cum(strong_bull) = ۰.۰۸ + ۰.۱۵ + ۰.۲۸ = ۰.۵۱
  - Cum(weak_bull) = ۰.۰۸ + ۰.۱۵ + ۰.۲۸ + ۰.۱۲ = ۰.۶۳

- رنج:
  - Cum(range) = ۰.۱۵

- نزولی:
  - Cum(shock_down) = ۰.۰۲
  - Cum(accel_bear) = ۰.۰۲ + ۰.۰۴ = ۰.۰۶
  - Cum(strong_bear) = ۰.۰۲ + ۰.۰۴ + ۰.۰۸ = ۰.۱۴
  - Cum(weak_bear) = ۰.۰۲ + ۰.۰۴ + ۰.۰۸ + ۰.۰۸ = ۰.۲۲

**نتیجه:** احتمال تجمعی دسته صعودی = ۰.۶۳، خنثی = ۰.۱۵، نزولی = ۰.۲۲. جمع کل این سه = ۱.۰ (صحیح).

## ۵. روند احتمالات در ۳۰ روز گذشته

### ۵.۱ هدف

سیستم باید **روند تغییرات احتمال اختصاصی و احتمال تجمعی هر سناریو در ۳۰ روز گذشته** را ارائه دهد. این روند به‌صورت جدول زمانی (روز به روز) نمایش داده می‌شود.

### ۵.۲ شرط اساسی: عدم استفاده از داده‌های آینده (No Look‑ahead Bias)

برای محاسبه احتمال اختصاصی و تجمعی در هر روز تاریخی `t`، **فقط از داده‌های موجود تا انتهای همان روز** استفاده می‌شود. به‌عبارت دیگر:

- در روز t، از داده‌های قیمت، حجم، اخبار، اندیکاتورها و ... که **قبل یا در همان روز t** ثبت شده‌اند، استفاده می‌شود.
- **هیچ داده‌ای از روزهای بعد از t** (آینده) نباید در محاسبه روز t لحاظ شود.
- این اصل برای تمام ۳۰ روز گذشته رعایت می‌شود.

### ۵.۳ روش محاسبه برای هر روز t

برای هر روز t از ۳۰ روز گذشته تا امروز:

1. **دریافت داده‌ها:** داده‌های قیمت (Open, High, Low, Close) و حجم (در صورت وجود) را برای دوره تا پایان روز t جمع‌آوری کنید.
2. **محاسبه اندیکاتورها:** تمام ۵۳+ اندیکاتور را بر اساس داده‌های موجود تا روز t محاسبه کنید.
3. **تشخیص الگوها و رژیم:** الگوهای کلاسیک، هارمونیک، کندل‌استیک و رژیم بازار را بر اساس همان داده‌ها تشخیص دهید.
4. **محاسبه احتمال اختصاصی:** با استفاده از مدل‌های آموزشی (که فقط بر روی داده‌های قبل از روز t آموزش دیده‌اند)، احتمال اختصاصی ۹ سناریو را محاسبه و نرمال کنید (جمع = ۱).
5. **محاسبه احتمال تجمعی:** طبق فرمول‌های بخش ۴، برای همان روز t احتمال تجمعی هر سناریو را محاسبه کنید.
6. **ذخیره نتایج:** مقادیر احتمال اختصاصی و تجمعی برای هر سناریو را در جدول روند ثبت کنید.

### ۵.۵ تحلیل روند احتمالات

پس از ساخت جدول ۳۰ روزه، سیستم باید یک **تحلیل توصیفی** از روند ارائه دهد. این تحلیل باید شامل موارد زیر باشد:

- **روند احتمال اختصاصی هر سناریو:** افزایشی / کاهشی / نوسانی / ثابت (بر اساس تغییرات ۳۰ روزه).
- **روند احتمال تجمعی هر سناریو:** به‌صورت توصیفی (تأثیر تغییرات اختصاصی بر تجمعی).
- **تغییرات معنادار:** نقاطی که احتمال اختصاصی یا تجمعی بیش از ۰.۰۵ تغییر کرده است.
- **هم‌گرایی/واگرایی:** بررسی همبستگی روند احتمالات با روند قیمت و سایر متغیرها (اختیاری).

**تأکید:** این تحلیل **فقط توصیفی** است و از هیچ فرمول مصنوعی (مانند Decay Factor) برای ساخت روند استفاده نمی‌کند. روند مستقیماً از داده‌های جدول استخراج می‌شود.

---

## ۶. توضیح در مورد فرمول Decay Factor (برای جلوگیری از ابهام)

فرمول `Decay_Factor_h = α × exp(-h/τ₁) + (1-α) × exp(-h/τ₂)` **فقط برای وزن‌دهی به گام‌های پیش‌بینی آینده در محاسبه `P_Bull_Forecast` و `P_Bear_Forecast`** استفاده می‌شود. این فرمول **به هیچ عنوان** در محاسبه روند تاریخی احتمالات (۳۰ روز گذشته) به کار نمی‌رود.

برای روند ۳۰ روز گذشته، مقادیر احتمال اختصاصی و تجمعی **مستقیماً از داده‌های واقعی هر روز** (که طبق روش بخش ۵.۳ محاسبه می‌شوند) استخراج می‌گردند و هیچ‌گونه عملگر زوال یا سنتز مصنوعی روی آن‌ها اعمال نمی‌شود.

## ۷. کد نمونه برای محاسبه احتمال تجمعی در یک روز (Python)

```python
def calculate_cumulative_probabilities(daily_individual_probs):
    """
    محاسبه احتمالات تجمعی در یک روز بر اساس قاعده پله‌ای.

    Args:
        daily_individual_probs: دیکشنری با کلیدهای سناریو و مقادیر احتمال اختصاصی در آن روز
        {
            'shock_up': 0.08,
            'accel_bull': 0.15,
            'strong_bull': 0.28,
            'weak_bull': 0.12,
            'range': 0.15,
            'weak_bear': 0.08,
            'strong_bear': 0.08,
            'accel_bear': 0.04,
            'shock_down': 0.02
        }

    Returns:
        دیکشنری احتمالات تجمعی در همان روز
    """
    # ترتیب سناریوها از شدید به خفیف
    bullish_order = ['shock_up', 'accel_bull', 'strong_bull', 'weak_bull']
    bearish_order = ['shock_down', 'accel_bear', 'strong_bear', 'weak_bear']

    result = {}

    # محاسبه پله‌ای برای صعودی
    cum = 0
    for scenario in bullish_order:
        cum += daily_individual_probs[scenario]
        result[f'cum_{scenario}'] = cum

    # رنج
    result['cum_range'] = daily_individual_probs['range']

    # محاسبه پله‌ای برای نزولی
    cum = 0
    for scenario in bearish_order:
        cum += daily_individual_probs[scenario]
        result[f'cum_{scenario}'] = cum

    return result


# مثال استفاده
daily_probs = {
    'shock_up': 0.08,
    'accel_bull': 0.15,
    'strong_bull': 0.28,
    'weak_bull': 0.12,
    'range': 0.15,
    'weak_bear': 0.08,
    'strong_bear': 0.08,
    'accel_bear': 0.04,
    'shock_down': 0.02
}

cumulative = calculate_cumulative_probabilities(daily_probs)
print(cumulative)
# خروجی:
# {
#   'cum_shock_up': 0.08,
#   'cum_accel_bull': 0.23,
#   'cum_strong_bull': 0.51,
#   'cum_weak_bull': 0.63,
#   'cum_range': 0.15,
#   'cum_shock_down': 0.02,
#   'cum_accel_bear': 0.06,
#   'cum_strong_bear': 0.14,
#   'cum_weak_bear': 0.22
# }
```

## ۸. جمع‌بندی قواعد کلیدی برای پیاده‌سازی

1. احتمال اختصاصی هر سناریو در هر روز، مستقل از روزهای دیگر است.
2. احتمال تجمعی هر سناریو در هر روز، مجموع احتمال اختصاصی آن سناریو و سناریوهای شدیدتر از آن در همان دسته است (فقط در همان روز).
3. جمع احتمال اختصاصی ۹ سناریو در هر روز = ۱ (نرمال‌سازی).
4. جمع احتمال تجمعی دسته‌های صعودی، خنثی و نزولی = ۱ (چون هر سناریو در یک دسته است و کل فضا را پوشش می‌دهند).
5. روند ۳۰ روزه احتمالات، جدولی است که هر روز آن بر اساس داده‌های تا انتهای همان روز محاسبه شده است (بدون نگاه به آینده).
6. هیچ‌گونه جمع احتمالات بین روزها وجود ندارد.
7. هیچ فرمول Decay یا سایر سنتزها در محاسبه روند استفاده نمی‌شود.
