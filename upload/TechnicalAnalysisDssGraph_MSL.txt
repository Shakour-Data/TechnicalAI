# 📚 مستند کامل و جامع: سیستم مکتب، سبک و لحن تحلیل (نسخه ۴.۱ - اصلاح‌شده برای سازگاری با اصول احتمال تجمعی و روند)

> **توجه:** این نسخه با هدف رفع ابهامات مربوط به «احتمال تجمعی» و «روند احتمالات» و برای درک کامل هوش مصنوعی بازنویسی شده است.  
> **نکته کلیدی:** احتمال تجمعی فقط در **یک روز مشخص** تعریف می‌شود و **جمع احتمالات روزهای مختلف** مجاز نیست. روند احتمالات در ۳۰ روز گذشته صرفاً از داده‌های واقعی هر روز (بدون استفاده از داده‌های آینده) محاسبه می‌شود و هیچ فرمول زوال (Decay) یا سنتز مصنوعی در آن به‌کار نمی‌رود.

---

## 🎯 معرفی کلی

سیستم **مکتب، سبک و لحن تحلیل** یک چارچوب هوشمند و خودکار برای تعیین **روش‌شناسی، ساختار ارائه و حالت احساسی** تحلیل‌های تولیدشده توسط سیستم گراف تصمیم است. این سیستم با استفاده از یادگیری ماشین، داده‌های بازار و بازخورد عملکرد، به‌صورت پویا مناسب‌ترین ترکیب را برای هر شرایط بازار و هر مخاطب خاص انتخاب می‌کند.

## ۱. مکتب تحلیل (School of Analysis)

### ۱.۱. تعریف و مفهوم

**مکتب تحلیل** به چارچوب فکری، روش‌شناسی و فلسفه تحلیلی گفته می‌شود که بر اساس آن، داده‌های بازار تفسیر و تحلیل می‌شوند. هر مکتب دارای اصول، ابزارها و قواعد خاص خود است که نحوه نگاه به بازار و استخراج سیگنال‌های معاملاتی را تعیین می‌کند.

### ۱.۲. مکاتب شش‌گانه

#### 📊 مکتب کلاسیک (Classical School)

```yaml
school_classical:
  id: "classical"
  name: "مکتب کلاسیک"
  name_en: "Classical School"
  
  # اصول بنیادین
  core_principles:
    - "قیمت همه‌چیز را تعدیل می‌کند"
    - "تاریخ خود را تکرار می‌کند"
    - "روندها تا زمانی که شکسته نشوند، معتبر هستند"
    
  # ابزارهای اصلی
  primary_tools:
    - "سطوح حمایت و مقاومت"
    - "خطوط روند و کانال‌ها"
    - "الگوهای کلاسیک (سر و شانه، مثلث، پرچم، گوه)"
    - "میانگین‌های متحرک ساده"
    
  # نشانه‌های تشخیص
  detection_signals:
    - "تعداد الگوهای کلاسیک تشخیص‌داده‌شده ≥ ۲"
    - "اعتبار الگوهای کلاسیک > ۰.۶"
    - "قدرت سطوح حمایت/مقاومت > ۳"
    - "نسبت الگوهای کلاسیک به کل الگوها > ۰.۴"
    
  # نقاط قوت
  strengths:
    - "سادگی و فهم آسان"
    - "کاربرد در تمام بازارها"
    - "تأیید بصری قوی"
    - "مناسب برای تایم‌فریم‌های بلندمدت"
    
  # نقاط ضعف
  weaknesses:
    - "تشخیص الگوها ذهنی است"
    - "در بازارهای با نوسان بالا کمتر مؤثر است"
    - "زمان‌بر بودن تشخیص"
    
  # وزن پایه
  base_weight: 0.30
  
  # ضریب تطبیق با شرایط
  adaptive_factors:
    trend_strength: 0.2
    pattern_quality: 0.4
    timeframe_weight: 0.2
    volatility_adjustment: 0.2
```

## ۲. سبک تحلیل (Analysis Style)

### ۲.۱. تعریف و مفهوم

**سبک تحلیل** به نحوه ارائه، ساختاردهی و جزئیات محتوای تحلیلی گفته می‌شود. سبک تعیین می‌کند که تحلیل چقدر مفصل باشد، بر چه جنبه‌هایی تأکید شود و برای چه مخاطبی مناسب است.

### ۲.۲. سبک‌های پنج‌گانه

#### 👔 سبک اجرایی و تصمیم‌گیری (Executive & Decision-Making)

```yaml
style_executive:
  id: "executive"
  name: "سبک اجرایی و تصمیم‌گیری"
  name_en: "Executive & Decision-Making Style"
  
  # ویژگی‌های اصلی
  characteristics:
    - "مختصر و متمرکز بر تصمیم"
    - "تأکید بر EMV (Expected Monetary Value)"
    - "مدیریت ریسک در اولویت"
    - "خلاصه اجرایی در ابتدا"
    - "استفاده از بولت‌پوینت‌ها"
    
  # مخاطب هدف
  target_audience:
    - "مدیران ارشد"
    - "سرمایه‌گذاران نهادی"
    - "مدیران صندوق‌ها"
    - "کمیته‌های سرمایه‌گذاری"
    
  # ساختار پیشنهادی
  structure:
    - "چکیده اجرایی (۱ پاراگراف)"
    - "تصمیم پیشنهادی (BUY/SELL/HOLD)"
    - "دلایل کلیدی (حداکثر ۵ مورد)"
    - "ریسک‌های اصلی"
    - "نتیجه‌گیری نهایی"
    
  # طول پیشنهادی
  length: "short (۲۰۰-۴۰۰ کلمه)"
  
  # شاخص‌های کلیدی
  key_indicators_priority:
    - "EMV"
    - "Risk-Reward Ratio"
    - "VaR"
    - "Max Drawdown"
    - "Confidence Score"
```

### ۵.۱. الگوریتم انتخاب مکتب

```python
def select_school(context):
    """
    انتخاب مکتب تحلیل بر اساس شرایط بازار و داده‌های موجود
    """
    # ۱. محاسبه وزن پایه هر مکتب
    school_weights = {}
    
    for school in SCHOOLS:
        # وزن پایه
        weight = school['base_weight']
        
        # ضریب دارایی
        weight *= get_asset_multiplier(school['id'], context['asset'])
        
        # ضریب تایم‌فریم
        weight *= get_timeframe_multiplier(school['id'], context['timeframe'])
        
        # ضریب رژیم بازار
        weight *= get_regime_multiplier(school['id'], context['regime'])
        
        # ضریب تطبیق با شرایط
        weight *= get_adaptive_factor(school['id'], context)
        
        school_weights[school['id']] = weight
    
    # ۲. نرمال‌سازی وزن‌ها
    total_weight = sum(school_weights.values())
    normalized_weights = {k: v/total_weight for k, v in school_weights.items()}
    
    # ۳. انتخاب مکاتب اصلی و فرعی
    sorted_schools = sorted(normalized_weights.items(), key=lambda x: x[1], reverse=True)
    
    primary_school = sorted_schools[0]
    secondary_school = sorted_schools[1]
    
    # ۴. بررسی شرط غالب بودن
    if primary_school[1] > 0.45:
        status = "confirmed"
    elif primary_school[1] > 0.35:
        status = "tentative"
    else:
        # اگر هیچ مکتبی غالب نباشد، مکتب ترکیبی انتخاب می‌شود
        primary_school = ('hybrid', 0.3)
        status = "hybrid"
    
    return {
        'primary': primary_school[0],
        'primary_weight': primary_school[1],
        'secondary': secondary_school[0],
        'secondary_weight': secondary_school[1],
        'status': status,
        'all_weights': normalized_weights,
        'reasoning': generate_school_reasoning(normalized_weights, context)
    }
```

### ۵.۲. الگوریتم انتخاب سبک

```python
def select_style(primary_school, context):
    """
    انتخاب سبک تحلیل بر اساس مکتب غالب و شرایط بازار
    """
    style_scores = {}
    
    for style in STYLES:
        # امتیاز سازگاری با مکتب
        compatibility = get_compatibility_score(primary_school, style['id'])
        
        # امتیاز تطابق با مخاطب
        audience_match = get_audience_match(style['id'], context['audience'])
        
        # امتیاز تطابق با شرایط بازار
        market_match = get_market_context_match(style['id'], context)
        
        # امتیاز نهایی
        score = (compatibility * 0.4) + \
                (audience_match * 0.3) + \
                (market_match * 0.2) + \
                (get_school_style_match(primary_school, style['id']) * 0.1)
        
        style_scores[style['id']] = score
    
    # انتخاب بهترین سبک
    primary_style = max(style_scores.items(), key=lambda x: x[1])
    secondary_style = sorted(style_scores.items(), key=lambda x: x[1], reverse=True)[1]
    
    return {
        'primary': primary_style[0],
        'primary_score': primary_style[1],
        'secondary': secondary_style[0],
        'secondary_score': secondary_style[1],
        'detail_level': get_detail_level(primary_style[1]),
        'length': get_style_length(primary_style[0]),
        'reasoning': generate_style_reasoning(primary_style, context)
    }
```

```python
def select_tone(primary_school, primary_style, context):
    """
    انتخاب لحن تحلیل بر اساس مکتب، سبک و شرایط بازار
    """
    tone_scores = {}
    
    for tone in TONES:
        # امتیاز تطابق با شرایط
        condition_match = check_tone_conditions(tone['id'], context)
        
        # امتیاز سازگاری با مکتب
        school_match = get_tone_school_match(tone['id'], primary_school)
        
        # امتیاز سازگاری با سبک
        style_match = get_tone_style_match(tone['id'], primary_style)
        
        # امتیاز شدت
        intensity = calculate_tone_intensity(tone['id'], context)
        
        score = (condition_match * 0.5) + \
                (school_match * 0.2) + \
                (style_match * 0.2) + \
                (intensity * 0.1)
        
        tone_scores[tone['id']] = score
    
    # انتخاب لحن اصلی
    primary_tone = max(tone_scores.items(), key=lambda x: x[1])
    
    # محاسبه شدت لحن
    intensity = calculate_final_intensity(primary_tone[0], context)
    
    # انتخاب لحن دوم
    secondary_tone = sorted(tone_scores.items(), key=lambda x: x[1], reverse=True)[1]
    
    return {
        'primary': primary_tone[0],
        'primary_score': primary_tone[1],
        'intensity': intensity,
        'secondary': secondary_tone[0],
        'secondary_score': secondary_tone[1],
        'keywords': get_tone_keywords(primary_tone[0], intensity),
        'reasoning': generate_tone_reasoning(primary_tone, context)
    }

Final_Weight_i = Σ_{layer=1}^{4} (Layer_Weight_layer × Factor_Score_layer_i)

که:
- Final_Weight_i: وزن نهایی مکتب/سبک/لحن i
- Layer_Weight_layer: وزن لایه (۰.۳۰، ۰.۲۵، ۰.۲۵، ۰.۲۰)
- Factor_Score_layer_i: امتیاز عامل i در لایه مربوطه

def update_weights_daily(performance_data):
    """
    به‌روزرسانی روزانه وزن‌ها بر اساس عملکرد واقعی
    """
    for school in SCHOOLS:
        # محاسبه عملکرد ۳ ماه اخیر
        win_rate = calculate_win_rate(school['id'], performance_data)
        sharpe = calculate_sharpe(school['id'], performance_data)
        drawdown = calculate_drawdown(school['id'], performance_data)

        adjustment_factor = 1.0
        adjustment_factor *= (1 + (win_rate - 0.55) * 0.5)  # افزایش/کاهش بر اساس نرخ برد
        adjustment_factor *= (1 + (sharpe - 1.5) * 0.2)     # افزایش/کاهش بر اساس شارپ
        adjustment_factor *= (1 - (drawdown - 0.15) * 0.3)  # کاهش در صورت افزایش ضرر
        
        # محدود کردن ضریب
        adjustment_factor = max(0.8, min(1.2, adjustment_factor))
        
        # به‌روزرسانی وزن
        school['base_weight'] *= adjustment_factor
        
    # نرمال‌سازی نهایی
    normalize_weights(SCHOOLS)
```

## ۱۰. پیوست: تعریف احتمال تجمعی و روند احتمالات

### ۱۰.۱. احتمال اختصاصی (Individual Probability)

**تعریف:** احتمال اختصاصی هر سناریو در یک روز مشخص، احتمال وقوع همان سناریو در آن روز است (بدون دخالت سناریوهای دیگر). مقدار آن عددی بین ۰ و ۱ است.

**شرط نرمال‌سازی:** در هر روز، مجموع احتمال اختصاصی تمام ۹ سناریو باید برابر با ۱ باشد:

```
P_ind(shock_up) + P_ind(accel_bull) + ... + P_ind(shock_down) = 1
```

### ۱۰.۲. احتمال تجمعی (Cumulative Probability)

**تعریف:** احتمال تجمعی یک سناریو در یک روز مشخص، **جمع احتمال اختصاصی همان سناریو و تمام سناریوهای شدیدتر از آن در همان دسته** است. این جمع‌کردن **فقط در همان روز** انجام می‌شود و **بین روزها هیچ جمعی وجود ندارد**.

**فرمول‌ها (برای هر روز t):**

- **دسته صعودی:**
  ```
  Cum(shock_up)    = P_ind(shock_up)
  Cum(accel_bull)  = P_ind(shock_up) + P_ind(accel_bull)
  Cum(strong_bull) = P_ind(shock_up) + P_ind(accel_bull) + P_ind(strong_bull)
  Cum(weak_bull)   = P_ind(shock_up) + P_ind(accel_bull) + P_ind(strong_bull) + P_ind(weak_bull)
  ```
- **دسته خنثی:**
  ```
  Cum(range) = P_ind(range)
  ```
- **دسته نزولی:**
  ```
  Cum(shock_down)  = P_ind(shock_down)
  Cum(accel_bear)  = P_ind(shock_down) + P_ind(accel_bear)
  Cum(strong_bear) = P_ind(shock_down) + P_ind(accel_bear) + P_ind(strong_bear)
  Cum(weak_bear)   = P_ind(shock_down) + P_ind(accel_bear) + P_ind(strong_bear) + P_ind(weak_bear)
  ```

**مثال:** با احتمالات اختصاصی {۰.۰۸، ۰.۱۵، ۰.۲۸، ۰.۱۲، ۰.۱۵، ۰.۰۸، ۰.۰۸، ۰.۰۴، ۰.۰۲}:
- Cum(weak_bull) = ۰.۰۸ + ۰.۱۵ + ۰.۲۸ + ۰.۱۲ = ۰.۶۳
- Cum(weak_bear) = ۰.۰۲ + ۰.۰۴ + ۰.۰۸ + ۰.۰۸ = ۰.۲۲

### ۱۰.۳. روند احتمالات (Probability Trend)

**تعریف:** روند احتمالات، نمایش **تغییرات احتمال اختصاصی و تجمعی هر سناریو در ۳۰ روز گذشته** است. این روند به‌صورت جدول ۳۰ ردیفه ارائه می‌شود.

**شرط اساسی (عدم نگاه به آینده):** برای محاسبه احتمال در هر روز تاریخی `t`، **فقط از داده‌های موجود تا انتهای همان روز** استفاده می‌شود. هیچ داده‌ای از روزهای بعد از `t` در محاسبه روز `t` لحاظ نمی‌شود.

**روش محاسبه:** برای هر روز t:
1. دریافت داده‌ها تا روز t
2. محاسبه اندیکاتورها و تشخیص الگوها بر اساس داده‌های تا روز t
3. محاسبه احتمال اختصاصی ۹ سناریو با مدل‌های آموزش‌دیده بر روی داده‌های قبل از t
4. نرمال‌سازی (جمع = ۱)
5. محاسبه احتمال تجمعی طبق فرمول‌های بخش ۱۰.۲
6. ثبت نتایج در جدول

**قالب جدول:** هر ردیف شامل تاریخ، شماره روز (۰ برای امروز، ‎-۱ برای دیروز، ...)، احتمال اختصاصی/تجمعی هر سناریو، و احتمال تجمعی دسته‌ای است.

6. **سیستم بازخورد** برای بهبود مستمر
7. **خروجی ساختاریافته** شامل داده‌های احتمال (اختصاصی و تجمعی) و روند ۳۰ روزه احتمالات

**نکات کلیدی برای هوش مصنوعی:**
- احتمال تجمعی فقط در همان روز محاسبه می‌شود.
- روند احتمالات از داده‌های واقعی ۳۰ روز گذشته (بدون نگاه به آینده) استخراج می‌شود.
- هیچ فرمول زوال یا سنتز مصنوعی در روند احتمالات استفاده نمی‌شود.
- خروجی نهایی به‌صورت ساختاریافته و آماده برای پرامپت تولید متن ارائه می‌شود.

**این سیستم آماده پیاده‌سازی و اتصال به پرامپت تولید متن تحلیلی است.**
