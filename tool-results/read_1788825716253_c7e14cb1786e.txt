    24→## ۱.۱ هدف سیستم
    25→
    26→این سیستم یک **پلتفرم جامع تحلیل تکنیکال بورس ایران** است که با استفاده از الگوریتم‌های پیشرفته و هوش مصنوعی، تحلیل چندلایه‌ای سهام، شاخص‌ها و بازارهای مالی ایران و جهانی ارائه می‌دهد. سیستم بدون وابستگی به سخت‌افزار خارجی یا مدل‌های سنگین پایتون، تمام محاسبات را در TypeScript خالص انجام می‌دهد.
    27→
    28→### ویژگی‌های اصلی:
    29→- **۶۰+ اندیکاتور تکنیکال**: RSI, MACD, ADX, Stochastic, Bollinger, Ichimoku, VWAP, و غیره
    30→- **۷ لایه موتور احتمال VDss**: از نمره خام تا احتمال مسیر
    31→- **۹ سناریو قیمتی**: از SC1 (شوک نزولی) تا SC9 (شوک صعودی)
    32→- **۳ موتور تشخیص رژیم**: فازی + مارکوف + رأی‌گیری وزنی
    33→- **تشخیص الگو**: ۱۶ الگوی کلاسیک + ۶ هارمونیک + ۱۶+ کندلی
    34→- **تولید متن هوشمند**: MSL (مکتب × سبک × لحن) + زبان فارسی
    35→- **پروفایل حجم تقریبی**: بدون نیاز به داده تیک-بای-تیک
    36→- **بازخورد تطبیقی**: سیستم یادگیری وزن‌ها بر اساس بازخورد کاربر
    37→

   183→
   184→### هدف
   185→موتور اصلی تحلیل تکنیکال که تمام اندیکاتورها، سطوح حمایت/مقاومت، و سیستم احتمال ۷ لایه VDss را پیاده‌سازی می‌کند.

   187→### ورودی‌ها

   243→### فرمول زاویه ترند
   244→
   245→```typescript
   246→angle = Math.atan((slope / avgPrice) * 100) * (180 / Math.PI)
   247→```
   248→
   249→- `slope`: شیب خط رگرسیون خطی قیمت‌های بسته
   250→- `avgPrice`: میانگین قیمت‌های بسته
   251→- `×100`: تبدیل نسبت به درصد قبل از atan (۱% رشد روزانه ≈ ۴۵°)
   252→
   253→### یکاهای نمره ترند
   254→
   255→```typescript
   256→s_trend = (r2 × 0.7) + (normalize(angle) × 0.3)
   257→```
   258→
   259→- `r2`: ضریب تعیین رگرسیون خطی (0 تا 1)
   260→- `normalize(angle)`: `(angle + 45) / 90` محدود به [0, 1]
   261→- زاویه‌های منفی (نزولی) مقادیر کمتر از ۰.۵ و زاویه‌های مثبت (صعودی) مقادیر بیشتر از ۰.۵ تولید می‌کنند

   265→## ۲.۲ ماژول تشخیص رژیم (`regime-engine.ts`)
   266→
   267→### هدف
   268→تشخیص رژیم بازار با سه موتور مستقل و ترکیب نهایی آنها. جایگزین GNN، HMM و Transformer Classifier.
   269→
   270→### ۵ وضع رژیم
   271→
   272→| وضع | شرح |
   273→|-----|------|
   274→| `TRENDING_UP` | روند صعودی قوی (ADX بالا + DI+ > DI-) |
   275→| `TRENDING_DOWN` | روند نزولی قوی (ADX بالا + DI- > DI+) |
   276→| `RANGING` | بازار رنج (ADX پایین + قیمت در BB) |
   277→| `VOLATILE` | نوسان بالا (ATR بالا + تغییرات زیاد) |
   278→| `BREAKOUT` | شکست سطح (حجم بالا + حرکت خارج از BB) |
   279→
   280→### موتور ۱: تشخیص فازی مبتنی بر قواعد
   281→
   282→```
   283→ورودی‌ها: ADX, RSI, %BB (موقعیت در بولینگر), +DI, -DI, شیب EMA, ATR
   284→         │
   285→         ▼
   286→توابع عضویت فازی: trimf (مثلثی) و trapmf (ذوزنقه‌ای)
   287→         │
   288→         ▼
   289→قواعد فازی:
   290→  - ADX>25 AND DI+>DI-  ──► μ(TRENDING_UP) = بالا
   291→  - ADX>25 AND DI->DI+  ──► μ(TRENDING_DOWN) = بالا
   292→  - ADX<20 AND price∈BB ──► μ(RANGING) = بالا
   293→  - ATR بالا            ──► μ(VOLATILE) = بالا
   294→  - حجم بالا AND شکست BB ──► μ(BREAKOUT) = بالا
   295→         │
   296→         ▼
   297→خروجی: { up: 0..1, down: 0..1, neutral: 0..1 }
   298→```
   299→
   300→### موتور ۲: زنجیره مارکوف ساده
   301→
   302→```
   303→ماتریس انتقال ۵×۵ (T):
   304→  T[i][j] = P(رژیم_j | رژیم_i)
   305→
   306→بروزرسانی:
   307→  ۱. محاسبه احتمال مشاهده از فازی: P(obs|state_j)
   308→  ۲. بروزرسانی بیز: π_j = Σ_i (π_i × T[i][j]) × P(obs|state_j)
   309→  ۳. نرمال‌سازی: Σπ = ۱
   310→
   311→بروزرسانی ماتریس انتقال:
   312→  - بعد از هر کندل: اگر رژیم تغییر کرد، افزایش T[old→new]
   313→  - فرسایش تدریجی: T *= (1 - decay) + uniform × decay
   314→```
   315→
   316→### موتور ۳: رأی‌گیری وزنی تطبیقی
   317→
   318→```
   319→اندیکاتورهای پایه: [MACD, Stochastic, RSI, OBV, MFI, ADX, BB]
   320→
   321→سیگنال هر اندیکاتور:
   322→  MACD: hist>0 → +1, hist<0 → -1, else → 0
   323→  Stoch: K>80 AND K<D → -1, K<20 AND K>D → +1, else → 0
   324→  RSI: >70 → -1, <30 → +1, else → 0
   325→  OBV: روند صعودی → +1, نزولی → -1
   326→  MFI: >80 → -1, <20 → +1, else → 0
   327→  ADX: DI+>DI- → +1, DI->DI+ → -1
   328→  BB: بالای باند بالا → -1, پایین باند پایین → +1
   329→
   330→رأی نهایی:
   331→  vote = Σ (signal_i × weight_i) / Σ |weight_i|
   332→
   333→وزن‌دهی تطبیقی:
   334→  - وزن اولیه: ۱.۰ برای همه
   335→  - نرخ فرسایش خطا: ۰.۰۵
   336→  - پیش‌بینی درست: وزن ثابت
   337→  - پیش‌بینی نادرست: weight *= (1 - 0.05)
   338→```

   350→### هدف
   351→ساخت پروفایل حجم تقریبی و شمارش تعداد برخورد از داده OHLCV، بدون نیاز به داده تیک-بای-تیک.
   352→
   353→### تابع `approximateVolumeProfile()`
   354→
   355→```
   356→ورودی: data: OHLCV[], numBins: number (پیش‌فرض ۱۰۰)
   357→         │
   358→         ▼
   359→۱. محدوده قیمت: [min(Low), max(High)]
   360→۲. ساخت N باکت قیمت با عرض مساوی
   361→         │
   362→         ▼
   363→۳. برای هر کندل:
   364→   - حجم بدنه: |close - open| / |high - low|
   365→   - حجم سایه بالا: (high - max(open,close)) / |high - low|
   366→   - حجم سایه پایین: (min(open,close) - low) / |high - low|
   367→   - توزیع حجم در باکت‌های مربوطه
   368→         │
   369→         ▼
   370→خروجی: VolumeProfileResult {
   371→  bins: [{ price, volume, volumePercent }],
   372→  poc: number,          // Point of Control - بیشترین حجم
   373→  valueAreaHigh: number, // بالای ناحیه ارزش (۷۰% حجم)
   374→  valueAreaLow: number,  // پایین ناحیه ارزش
   375→  vwap: number          // Volume Weighted Average Price
   376→}
   377→```
   378→
   379→### تابع `countTouch()`
   380→
   381→```
   382→ورودی: data: OHLCV[], level: number, tolerance: number (پیش‌فرض ۰.۰۰۲ = ۰.۲%)
   383→         │
   384→         ▼
   385→برای هر کندل:
   386→  - |High - level| / level ≤ tolerance → touchCount++
   387→  - |Low - level| / level ≤ tolerance → touchCount++
   388→         │
   389→         ▼
   390→خروجی: TouchCountResult { touchCount, recentTouches, avgVolume }
   391→```

   501→## ۲.۶ ماژول رگرسیون لجستیک (`ml-logistic.ts`)
   502→
   503→### هدف
   504→پیاده‌سازی کامل رگرسیون لجستیک در TypeScript خالص با L2 regularization.
   505→
   506→### کلاس `StandardScaler`
   507→
   508→```
   509→fit(X): محاسبه mean و std هر ویژگی
   510→transform(X): (X - mean) / std
   511→fitTransform(X): fit + transform
   512→inverseTransform(X): X × std + mean
   513→```
   514→
   515→### کلاس `LogisticRegressionModel`
   516→
   517→```
   518→هایپرپارامترها:
   519→  - lr: 0.01 (نرخ یادگیری)
   520→  - l2Lambda: 0.01 (ضریب L2)
   521→  - maxIter: 200 (حداکثر تکرار)
   522→  - classWeight: 'balanced' (وزن‌دهی متوازن کلاس‌ها)
   523→
   524→آموزش:
   525→  ۱. مقداردهی اولیه وزن‌ها با صفر
   526→  ۲. برای هر تکرار:
   527→     - z = X × w + b
   528→     - pred = sigmoid(z)
   529→     - gradient = X^T × (pred - y) / n + 2 × λ × w
   530→     - w -= lr × gradient
   531→     - b -= lr × mean(pred - y)
   532→  ۳. بازگرداندن { weights, bias, accuracy, loss }
   533→```
   534→
   535→### کلاس `AdaptiveWeightModel`
   536→
   537→```
   538→استفاده از LogisticRegressionModel + StandardScaler
   539→
   540→متدها:
   541→  - train(X, y): آموزش با اعتبارسنجی TimeSeriesSplit
   542→  - predictScore(x): خروجی ۰ تا ۱ (احتمال صعودی)
   543→  - predictBatch(X): پیش‌بینی دسته‌ای با fallback [0.5, 0.5]
   544→  - getAdaptiveParams(): پارامترهای تطبیقی برای ta-engine
   545→  - getEdgeCoefficients(): ضرایب یال برای decision-graph
   546→```

   894→### `calcTrend(data: OHLCV[], period: number): TrendResult`
   895→
   896→**هدف**: محاسبه ترند با رگرسیون خطی و زاویه.
   897→
   898→**پارامترها**:
   899→- `data`: داده OHLCV
   900→- `period`: دوره رگرسیون (پیش‌فرض ۲۰)
   901→
   902→**خروجی**:
   903→```typescript
   904→{
   905→  slope: number,      // شیب خط رگرسیون
   906→  intercept: number,  // عرض از مبدأ
   907→  r2: number,         // ضریب تعیین

   911→```
   912→

   914→```
   915→angle = atan((slope / avgPrice) × 100) × (180 / π)
   916→```
   917→- ×100 تبدیل نسبت شیب/قیمت به درصد قبل از atan
   918→- نتیجه: ۱% رشد روزانه ≈ ۴۵°

   922→### `linearRegression(y: number[]): { slope, intercept, r2 }`
   923→
   924→**هدف**: رگرسیون خطی کمترین مجذرات بر داده‌های سری زمانی.
   925→
   926→**الگوریتم**:
   927→```
   928→x = [0, 1, 2, ..., n-1]  (ایندکس زمانی)
   929→slope = (n×Σxy - Σx×Σy) / (n×Σx² - (Σx)²)
   930→intercept = (Σy - slope×Σx) / n
   931→r2 = 1 - SS_res / SS_tot
   932→```

  1005→
  1006→### `updateRegimeTransition(chain: MarkovChain, fromState: RegimeType, toState: RegimeType): void`
  1007→
  1008→**هدف**: بروزرسانی ماتریس انتقال بعد از مشاهده تغییر رژیم.
  1009→
  1010→**الگوریتم**:
  1011→```
  1012→T[from][to] += 1
  1013→فرسایش: T[i][j] = T[i][j] × (1 - 0.001) + 0.001 × uniform
  1014→نرمال‌سازی هر سطر: Σ_j T[i][j] = 1
  1015→```
  1016→

  1018→
  1019→### `propagateMarkov(chain: MarkovChain, observation: FuzzyOutput): number[]`
  1020→
  1021→**هدف**: انتشار رو به جلو با بروزرسانی بیز.
  1022→
  1023→**الگوریتم**:
  1024→```
  1025→برای هر وضع j:
  1026→  π_new[j] = Σ_i (π[i] × T[i][j]) × P(observation | state_j)
  1027→
  1028→نرمال‌سازی: Σπ = 1
  1029→```
  1030→
  1031→**احتمال مشاهده** `P(obs | state_j)`:
  1032→- از عضویت‌های فازی به عنوان likelihood استفاده می‌شود
  1033→- هر وضع رژیم به یک عضویت فازی نگاشت می‌شود
  1034→

  1204→#### `recordFeedback(predictionId, isCorrect): void`
  1205→
  1206→**هدف**: ثبت بازخورد کاربر و راه‌اندازی بروزرسانی وزن.
  1207→
  1208→**الگوریتم**:
  1209→```
  1210→۱. علامت‌گذاری پیش‌بینی به عنوان درست/نادرست
  1211→۲. استخراج سناریو و جهت
  1212→۳. فراخوانی updateWeightsFromFeedback()
  1213→۴. ذخیره در localStorage
  1214→```
  1215→
  1216→#### `updateWeightsFromFeedback(prediction, isCorrect): void`
  1217→
  1218→**الگوریتم**:
  1219→```
  1220→نرخ یادگیری تطبیقی:
  1221→  recentAccuracy = correct / total (۲۰ اخیر)
  1222→  اگر recentAccuracy > 0.7: η = 0.01 × 0.5
  1223→  اگر recentAccuracy < 0.3: η = 0.01 × 2.0
  1224→  در غیر این صورت: η = 0.01
  1225→
  1226→بروزرسانی وزن:
  1227→  اگر isCorrect:
  1228→    weight += η × 0.1
  1229→  در غیر این صورت:
  1230→    weight -= η × 0.1
  1231→
  1232→محدودسازی: weight ∈ [0.5, 2.0]
  1233→```
  1234→
  1235→#### `getAdaptiveWeights(): Record<string, number>`
  1236→
  1237→**خروجی**: نقشه کلید→وزن شامل تمام وزن‌های تطبیقی.
  1238→
