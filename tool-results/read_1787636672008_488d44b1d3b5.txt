     5→## 🎯 معرفی سیستم
     6→
     7→**سیستم گراف تصمیم تحلیل تکنیکال پیشرفته (نسخه ۳.۰)** یک چارچوب کامل، خودکار، علمی، عملیاتی و هوشمند برای تحلیل بازارهای مالی است که از **یادگیری ماشین پیشرفته، یادگیری عمیق، یادگیری تقویتی، پردازش زبان طبیعی و گراف‌های عصبی** برای پیش‌بینی قیمت در بازه‌های **۱ تا ۳۰ جلسه معاملاتی** استفاده می‌کند. این سیستم تمام محاسبات اندیکاتورها، تشخیص الگوها، تحلیل واگرایی‌ها، مدیریت ریسک، ساخت گراف تصمیم و تولید گزارش‌های تحلیلی را به‌صورت خودکار و هوشمند انجام می‌دهد.

    41→## 🎯 اهداف و الزامات کلیدی
    42→
    43→### الزامات حیاتی (Must-Have)
    44→
    45→1. **سیستم کاملاً خودکار و خودکفا**:
    46→   - محاسبه خودکار **۵۳+ اندیکاتور و اسیلاتور**
    47→   - تشخیص خودکار **الگوهای کلاسیک، هارمونیک، کندل‌استیک و امواج الیوت**
    48→   - بدون نیاز به محاسبات دستی یا ورودی خارجی
    49→
    50→2. **مدیریت هوشمند داده‌های حجم**:
    51→   - در صورت عدم وجود داده حجم، حذف خودکار ۱۱ اندیکاتور وابسته به حجم
    52→   - بازتوزیع وزن‌های حذف‌شده به‌طور متناسب بین سایر اندیکاتورها
    53→
    54→3. **پیش‌بینی قیمت با یادگیری ماشین پیشرفته**:
    55→   - پیش‌بینی قیمت برای **۱ تا ۳۰ جلسه معاملاتی**
    56→   - استفاده از **LSTM، GRU، Transformer، TCN، Diffusion Models**
    57→   - محاسبه اندیکاتورها بر اساس قیمت‌های پیش‌بینی‌شده
    58→   - شناسایی واگرایی‌های فعلی و آینده
    59→
    60→4. **یادگیری تقویتی برای استراتژی معاملاتی**:
    61→   - استفاده از **DQN، PPO، Actor-Critic**
    62→   - یادگیری استراتژی‌های بهینه به‌صورت خودکار
    63→
    64→5. **پردازش زبان طبیعی (NLP) برای اخبار**:
    65→   - تحلیل احساسات با **FinBERT، BERT، GPT**
    66→   - تشخیص رویدادهای مهم و تأثیر آنها
    67→
    68→6. **ضرایب پویا با یادگیری ماشین**:
    69→   - ضرایب اختصاصی برای هر ابزار مالی
    70→   - به‌روزرسانی روزانه ضرایب با Bayesian Weighting + Meta-Learning
    71→
    72→7. **خروجی سه‌گانه**:
    73→   - **مکتب تحلیل** (School of Analysis)
    74→   - **سبک تحلیل** (Analysis Style)
    75→   - **لحن تحلیل** (Analysis Tone)
    76→
    77→8. **مدیریت ریسک کامل**:
    78→   - محاسبه حجم موقعیت بر اساس فرمول Kelly Modified + RL
    79→   - تعیین حد ضرر و حد سود بر اساس ATR و ساختار بازار
    80→   - پایش مداوم ریسک با VaR، Expected Shortfall، Conformal Prediction
    81→
    82→9. **تشخیص رژیم بازار پیشرفته**:
    83→   - شناسایی ۵ رژیم مختلف بازار با GNN + HMM
    84→   - تطبیق استراتژی با رژیم غالب
    85→
    86→10. **ارزیابی عملکرد و Backtesting جامع**:
    87→    - پایش مداوم عملکرد سیستم
    88→    - محاسبه معیارهای عملکرد (Sharpe، Sortino، Profit Factor)
    89→    - بازخورد خودکار برای بهبود

    93→## 📐 مبانی علمی و قوانین حاکم
    94→
    95→### ۱. قوانین علمی تحلیل تکنیکال
    96→
    97→#### اصل اول: سه فرضیه اصلی
    98→```
    99→فرضیه ۱: قیمت همه‌چیز را تعدیل می‌کند (Price Discounts Everything)
   100→فرضیه ۲: قیمت‌ها در روندها حرکت می‌کنند (Prices Move in Trends)
   101→فرضیه ۳: تاریخ خود را تکرار می‌کند (History Repeats Itself)
   102→```
   103→
   104→#### اصل دوم: ترکیب اندیکاتورها
   105→```
   106→قانون ۱: هرگز از یک اندیکاتور به‌تنهایی استفاده نکنید
   107→قانون ۲: حداقل از ۳ اندیکاتور از ۳ خانواده مختلف استفاده کنید
   108→قانون ۳: هم‌جهتی سیگنال‌ها اعتماد را افزایش می‌دهد
   109→قانون ۴: واگرایی‌ها سیگنال‌های قوی برگشت هستند
   110→قانون ۵: حجم معاملات باید برای تأیید سیگنال‌ها استفاده شود
   111→قانون ۶: تایم‌فریم‌های بالاتر برای تعیین روند اصلی اهمیت دارند
   112→```
   113→
   114→#### اصل سوم: مدیریت ریسک علمی
   115→```
   116→قانون ۱: ریسک هر معامله نباید از ۱-۲٪ سرمایه تجاوز کند
   117→قانون ۲: نسبت ریسک به بازده حداقل ۱:۲ باشد
   118→قانون ۳: استفاده از حد ضرر (Stop Loss) اجباری است
   119→قانون ۴: حجم معاملات بر اساس اطمینان و فاصله اطمینان تنظیم شود
   120→قانون ۵: در شرایط نوسان بالا، حجم معاملات کاهش یابد
   121→```
   122→
   123→### ۲. قوانین گراف تصمیم
   124→
   125→```
   126→قانون ۱: هر گره حداقل ۳ یال خروجی دارد
   127→قانون ۲: جمع احتمالات خروجی از هر گره = ۱
   128→قانون ۳: گره‌های تصمیم‌گیری حداکثرکننده EMV هستند
   129→قانون ۴: گره‌های پایانی دارای KPI نهایی هستند
   130→قانون ۵: گراف بدون دور (Acyclic) است
   131→قانون ۶: هر گره تصمیم باید دارای حداقل یک گره ریسک باشد
   132→قانون ۷: خروجی هر گره باید به گره بعدی متصل باشد
   133→```
   134→
   135→### ۳. قوانین پیش‌بینی با یادگیری ماشین
   136→
   137→```
   138→قانون ۱: Cross-Validation 5-Fold
   139→قانون ۲: داده‌های آموزشی (۶۰٪)، اعتبارسنجی (۲۰٪) و تست (۲۰٪)
   140→قانون ۳: عدم استفاده از داده‌های آینده (Forward-Looking Bias)
   141→قانون ۴: Walk-Forward Analysis برای تأیید مدل
   142→قانون ۵: تست بر روی دوره‌های مختلف بازار (Bull, Bear, Sideways)
   143→قانون ۶: استفاده از Ensemble Methods برای کاهش خطا
   144→قانون ۷: به‌روزرسانی مدل به‌صورت دوره‌ای
   145→قانون ۸: استفاده از Reinforcement Learning با محیط‌های شبیه‌سازی‌شده
   146→قانون ۹: استفاده از Transfer Learning برای دارایی‌های جدید
   147→قانون ۱۰: استفاده از Conformal Prediction برای تضمین‌های آماری
   148→```

   238→## 🧮 سیستم محاسبه خودکار اندیکاتورها
   239→
   240→### معماری محاسبه
   241→
   242→```yaml
   243→indicator_calculation_engine:
   244→  input_requirements:
   245→    price_data:
   246→      - open: [لیست قیمت‌های باز شدن]
   247→      - high: [لیست بالاترین قیمت‌ها]
   248→      - low: [لیست پایین‌ترین قیمت‌ها]
   249→      - close: [لیست قیمت‌های بسته شدن]
   250→      - timestamp: [لیست زمان‌ها]
   251→    volume_data: [اختیاری - لیست حجم معاملات]
   252→  
   253→  output:
   254→    indicators_matrix: [۵۳+ × تعداد نقاط داده]
   255→    pattern_detection_results: [لیست الگوهای تشخیص‌داده‌شده]
   256→    divergence_results: [لیست واگرایی‌های تشخیص‌داده‌شده]
   257→    scenario_probabilities: [احتمالات ۹ سناریو]
   258→    market_regime: [رژیم بازار فعلی]
   259→  
   260→  validation:
   261→    - بررسی کامل بودن داده‌ها
   262→    - تشخیص وجود/عدم وجود داده‌های حجم
   263→    - حذف خودکار اندیکاتورهای وابسته به حجم در صورت عدم وجود داده
   264→    - بازتوزیع وزن‌های اندیکاتورهای حذف‌شده
   265→    - بررسی سلامت داده‌ها (Outlier Detection)
   266→    - پر کردن داده‌های گم‌شده (Interpolation)
   267→```

   408→## 📐 محاسبه قدرت روند و سطوح حمایت/مقاومت
   409→
   410→### ۱. قدرت روند (Trend Strength)
   411→
   412→#### فرمول اصلی:
   413→```
   414→Trend_Strength = (W1 × ADX_Normalized) + 
   415→                 (W2 × Slope_Strength) + 
   416→                 (W3 × MA_Alignment) + 
   417→                 (W4 × Price_Position) + 
   418→                 (W5 × Momentum_Strength) + 
   419→                 (W6 × Pullback_Quality) + 
   420→                 (W7 × GNN_Correlation_Strength)
   421→```
   422→
   423→#### مؤلفه‌ها:
   424→
   425→**الف) ADX نرمال‌شده:**
   426→```
   427→ADX_Normalized = min(ADX / 60, 1)
   428→ADX < 20: روند ضعیف
   429→20 < ADX < 40: روند متوسط
   430→ADX > 40: روند قوی
   431→```
   432→
   433→**ب) قدرت شیب روند:**
   434→```
   435→Slope_Strength = (EMA_Current - EMA_Previous) / (EMA_Current × Volatility_Adjustment)
   436→Slope > 0.01: شیب صعودی قوی
   437→0.005 < Slope < 0.01: شیب صعودی متوسط
   438→Slope < 0.005: شیب ضعیف یا خنثی
   439→```
   440→
   441→**ج) هم‌راستایی میانگین‌های متحرک:**
   442→```
   443→MA_Alignment = (Alignment_Count / 5)
   444→روند صعودی: EMA10 > EMA20 > EMA50 > EMA100 > EMA200
   445→روند نزولی: EMA10 < EMA20 < EMA50 < EMA100 < EMA200
   446→```
   447→
   448→**د) موقعیت قیمت نسبت به میانگین‌ها:**
   449→```
   450→Price_Position = (Price - EMA50) / (Price + EMA50) × 2
   451→Price_Position > 0.05: موقعیت قوی صعودی
   452→0.02 < Price_Position < 0.05: موقعیت صعودی متوسط
   453→-0.02 < Price_Position < 0.02: موقعیت خنثی
   454→```
   455→
   456→**ه) قدرت مومنتوم:**
   457→```
   458→Momentum_Strength = (RSI_Normalized + MACD_Strength) / 2
   459→RSI_Normalized = |RSI - 50| / 30
   460→MACD_Strength = |MACD_Histogram| / (MACD_Histogram_StdDev)
   461→```
   462→
   463→**و) کیفیت اصلاح‌ها:**
   464→```
   465→Pullback_Quality = (1 - Pullback_Depth) × (1 - Pullback_Time)
   466→اصلاح ۰-۲۰٪: عالی
   467→اصلاح ۲۰-۴۰٪: خوب
   468→اصلاح ۴۰-۶۰٪: متوسط
   469→اصلاح > ۶۰٪: ضعیف
   470→```
   471→
   472→**ز) قدرت همبستگی GNN:**
   473→```
   474→GNN_Correlation_Strength = (Correlation_with_Bullish_Assets - Correlation_with_Bearish_Assets) / 2
   475→اگر همبستگی با دارایی‌های صعودی قوی باشد → 1.0
   476→اگر همبستگی با دارایی‌های نزولی قوی باشد → 0.0
   477→```
   478→
   479→### ۲. قدرت سطوح حمایت/مقاومت (SR Strength)
   480→
   481→#### فرمول اصلی:
   482→```
   483→SR_Strength = (W1 × Touch_Count) + 
   484→              (W2 × Time_Validity) + 
   485→              (W3 × Volume_Profile) + 
   486→              (W4 × Volatility_Adjustment) + 
   487→              (W5 × Historical_Significance) + 
   488→              (W6 × Fibonacci_Confluence) + 
   489→              (W7 × Pattern_Support) + 
   490→              (W8 × GNN_Volume_Strength)
   491→```
   492→
   493→#### مؤلفه‌ها:
   494→
   495→**الف) تعداد برخوردها:**
   496→```
   497→Touch_Count = min(Brkhord_Count / 5, 1)
   498→۵+ برخورد: ۱.۰ (قوی‌ترین)
   499→۳-۴ برخورد: ۰.۶-۰.۸ (متوسط-قوی)
   500→۱-۲ برخورد: ۰.۲-۰.۴ (ضعیف)
   501→```
   502→
   503→**ب) اعتبار زمانی:**
   504→```
   505→Time_Validity = min(Timespan / 180, 1)
   506→> ۱۸۰ روز: ۱.۰ (بسیار معتبر)
   507→۶۰-۱۸۰ روز: ۰.۵-۰.۸ (معتبر)
   508→< ۶۰ روز: ۰.۲-۰.۴ (کم‌اعتبار)
   509→```
   510→
   511→**ج) پروفایل حجم در سطح:**
   512→```
   513→Volume_Profile = (Volume_at_Level / Average_Volume) × Normalization
   514→Volume > 1.5×Average: قوی (> ۰.۷)
   515→Volume > 1.0×Average: متوسط (۰.۴-۰.۷)
   516→Volume < 1.0×Average: ضعیف (< ۰.۴)
   517→```
   518→
   519→**د) تعدیل نوسان:**
   520→```
   521→Volatility_Adjustment = 1 - (ATR / Price)
   522→نوسان کم (ATR/Price < 0.02): تعدیل = ۰.۹۸
   523→نوسان زیاد (ATR/Price > 0.05): تعدیل = ۰.۹۵
   524→```
   525→
   526→**ه) اهمیت تاریخی:**
   527→```
   528→Historical_Significance = (Major_High_Count + Major_Low_Count) / 4
   529→```
   530→
   531→**و) هم‌گرایی فیبوناچی:**
   532→```
   533→Fibonacci_Confluence = min(Fibonacci_Levels / 3, 1)
   534→۳+ نسبت تلاقی: قوی (> ۰.۷)
   535→۲ نسبت تلاقی: متوسط (۰.۵)
   536→۱ نسبت تلاقی: ضعیف (۰.۳)
   537→```
   538→
   539→**ز) پشتیبانی الگوی قیمتی:**
   540→```
   541→Pattern_Support = (Classic_Pattern_Weight + Harmonic_Pattern_Weight) / 2
   542→```
   543→
   544→**ح) قدرت حجم GNN:**
   545→```
   546→GNN_Volume_Strength = GNN_Volume_Signal (از گراف عصبی)
   547→اگر حجم در دارایی‌های مرتبط بالا باشد → قوی
   548→اگر حجم در دارایی‌های مرتبط کم باشد → ضعیف
   549→```

   658→فرمول محاسبه اندیکاتورها در آینده:
   659→

   661→

   666→  Indicator_i[t+h] = f_i(P_predicted[t+1..t+h])

   670→  - اگر داده حجم موجود نباشد: اندیکاتور محاسبه نشود

   673→  ΔIndicator_i[h] = Indicator_i[t+h] - Indicator_i[t+h-1]
   674→

   676→  Turning_Point[h] = (Direction_Change_Indicator_i)
   677→
   678→نکته مهم:
   679→- برای گام‌های ۱-۵: ترکیب داده‌های واقعی (۲۰۰ روز قبل) + پیش‌بینی
   680→- برای گام‌های ۶-۳۰: استفاده از داده‌های پیش‌بینی‌شده
   681→- برای دوره‌های بلندتر از گام پیش‌بینی: استفاده از داده‌های واقعی
   682→```

   684→### ۳. محاسبه فاصله اطمینان با Conformal Prediction
   685→
   686→```yaml
   687→conformal_prediction:
   688→  - Split Conformal Prediction
   689→    - داده‌ها به دو بخش تقسیم می‌شوند
   690→    - بخش اول برای آموزش مدل
   691→    - بخش دوم برای محاسبه توزیع خطاها
   692→    - خروجی: فواصل اطمینان با تضمین آماری
   693→    
   694→  - Quantile Regression
   695→    - q = 0.05: حد پایین (Lower Bound)
   696→    - q = 0.50: پیش‌بینی میانه (Median Forecast)
   697→    - q = 0.95: حد بالا (Upper Bound)
   698→    
   699→  - Monte Carlo Dropout
   700→    - ۵۰ بار اجرای مدل با Dropout فعال
   701→    - محاسبه واریانس خروجی‌ها
   702→    - خروجی: توزیع پیش‌بینی‌ها
   703→    
   704→  - Bayesian Neural Networks (BNN)
   705→    - توزیع وزنه‌ها
   706→    - خروجی: میانگین + واریانس
   707→
   708→Confidence_Interval = [Forecast_q05, Forecast_q95]
   709→
   710→برای هر گام h:
   711→  CI_Width[h] = Forecast_q95[h] - Forecast_q05[h]
   712→  CI_Percentage[h] = (CI_Width[h] / Forecast_Median[h]) × 100

   799→### ۲. محاسبه وزن‌های پویا با یادگیری بیزین
   800→
   801→```
   802→فرمول اصلی وزن‌دهی با یادگیری بیزین:
   803→
   804→W_i = P(Success | Tool_i) × Prior_i / Σ(P(Success | Tool_j) × Prior_j)
   805→
   806→که:
   807→- P(Success | Tool_i): احتمال موفقیت با استفاده از ابزار i
   808→  - محاسبه: (Win_Rate_i / 100) × (Sharpe_Ratio_i / 2)
   809→  
   810→- Prior_i: وزن اولیه
   811→  - اندیکاتورهای روند: ۰.۲۸
   812→  - اسیلاتورها: ۰.۲۵
   813→  - اندیکاتورهای حجم (در صورت وجود): ۰.۱۵
   814→  - اندیکاتورهای نوسان: ۰.۱۰
   815→  - اندیکاتورهای پیشرو: ۰.۱۲
   816→  - الگوها: ۰.۱۰
   817→  - مجموع Prior = ۱
   818→
   819→- در صورت عدم وجود داده حجم:
   820→  - Prior_Volume = 0
   821→  - بازتوزیع Prior_Volume بین سایر دسته‌ها
   822→```
   823→
   824→### ۳. بازتوزیع وزن‌ها در صورت عدم وجود داده حجم
   825→
   826→```
   827→الگوریتم بازتوزیع وزن‌ها:
   828→
   829→مرحله ۱: شناسایی اندیکاتورهای وابسته به حجم
   830→  - لیست: MFI, PVO, Volume, OBV, A/D, VPT, VWAP, VOSC, VAP, Chaikin A/D, Force Index
   831→  - تعداد: ۱۱ مورد
   832→
   833→مرحله ۲: محاسبه وزن کل حذف‌شده
   834→  Weight_Removed = Σ(W_i) برای i در لیست بالا
   835→
   836→مرحله ۳: محاسبه وزن باقی‌مانده
   837→  Weight_Remaining = 1 - Weight_Removed
   838→
   839→مرحله ۴: بازتوزیع وزن‌های حذف‌شده
   840→  برای هر دسته باقی‌مانده:
   841→    Weight_New_Category = Weight_Old_Category + (Weight_Old_Category / Weight_Remaining) × Weight_Removed
   842→
   843→مرحله ۵: نرمال‌سازی نهایی
   844→  - اطمینان از Σ W_i = 1
   845→  - گرد کردن به ۳ رقم اعشار
   846→```

  1023→### ۱. محاسبه حجم موقعیت (Position Sizing)

  1026→position_sizing:
  1027→  method: "Kelly Criterion Modified + RL"
  1028→  
  1029→  kelly_formula: |
  1030→    f* = (p × b - q) / b
  1031→    f* = سهم بهینه سرمایه برای هر معامله
  1032→    p = احتمال موفقیت (Win Rate)
  1033→    q = احتمال شکست (Loss Rate) = 1 - p

  1036→  modified_kelly: |

  1041→    - Confidence > 0.80: 1.0
  1042→    - Confidence 0.70-0.80: 0.75

  1050→    - خروجی: ضریب تنظیم حجم (0.5-1.5)

  1512→## 🧮 محاسبه احتمالات نهایی و تجمعی
  1513→
  1514→### ۱. احتمال صعودی نهایی
  1515→
  1516→```
  1517→P_Bull_Final = α × P_Bull_Current + (1-α) × P_Bull_Forecast
  1518→
  1519→که:
  1520→α = 0.5 (وزن وضعیت فعلی، قابل تنظیم با ML)
  1521→
  1522→P_Bull_Current = Σ(W_i_Current × Signal_Bull_i_Current) + Σ(Divergence_Impact_i_Current) + GNN_Bullish_Impact + NLP_Bullish_Impact
  1523→
  1524→P_Bull_Forecast = Σ_{h=1}^{30} [W_Forecast_h × (Σ(W_i_Forecast_h × Signal_Bull_i_Forecast_h) + Σ(Divergence_Impact_i_Forecast_h))]
  1525→```
  1526→
  1527→### ۲. احتمال نزولی نهایی
  1528→
  1529→```
  1530→P_Bear_Final = α × P_Bear_Current + (1-α) × P_Bear_Forecast
  1531→```
  1532→
  1533→### ۳. احتمال خنثی نهایی
  1534→
  1535→```
  1536→P_Neutral_Final = 1 - (P_Bull_Final + P_Bear_Final)
  1537→```
  1538→
  1539→### ۴. وزن‌دهی به گام‌های پیش‌بینی با تابع زوال نمایی دوگانه
  1540→
  1541→```
  1542→Decay_Factor_h = α × exp(-h/τ₁) + (1-α) × exp(-h/τ₂)
  1543→
  1544→که:
  1545→- h: شماره گام پیش‌بینی (۱ تا ۳۰)
  1546→- α = 0.7 (وزن جزء کوتاه‌مدت)
  1547→- τ₁ = 5 (ثابت زمانی کوتاه‌مدت)
  1548→- τ₂ = 20 (ثابت زمانی بلندمدت)
  1549→
  1550→W_Forecast_h = Decay_Factor_h / Σ_{j=1}^{30} Decay_Factor_j
  1551→```
  1552→
  1553→### ۵. محاسبه سناریوی نهایی
  1554→
  1555→```
  1556→برای هر سناریوی S (۱ تا ۹):
  1557→P_Scenario_S = P_Bull_Final × Conditional_Probability_S_Bull + 
  1558→               P_Bear_Final × Conditional_Probability_S_Bear +
  1559→               P_Neutral_Final × Conditional_Probability_S_Neutral
  1560→
  1561→سناریوی نهایی = argmax(P_Scenario_S)
  1562→اطمینان نهایی = P_Scenario_S / Σ P_Scenario_i
  1563→```
  1564→
  1565→### ۶. محاسبه احتمالات تجمعی (Cumulative Probabilities)
  1566→
  1567→#### فرمول‌های احتمالات تجمعی:
  1568→
  1569→```
  1570→P_Bullish_Cumulative = P_Scenario_1 + P_Scenario_2 + P_Scenario_3 + P_Scenario_4
  1571→
  1572→P_Neutral_Cumulative = P_Scenario_5
  1573→
  1574→P_Bearish_Cumulative = P_Scenario_6 + P_Scenario_7 + P_Scenario_8 + P_Scenario_9
  1575→
  1576→جمع کل = P_Bullish_Cumulative + P_Neutral_Cumulative + P_Bearish_Cumulative = 1.0
  1577→```
  1578→
  1579→#### احتمالات تجمعی وزن‌دار با شدت (Severity-Weighted):
  1580→
  1581→```
  1582→P_Bullish_Weighted = Σ (P_Scenario_i × Severity_Factor_i) برای i = 1 تا 4
  1583→
  1584→Severity_Factor:
  1585→- شوک صعودی (سناریو ۱): 1.0 (بیشترین شدت)
  1586→- صعودی شتاب‌دار (سناریو ۲): 0.8
  1587→- صعودی قوی (سناریو ۳): 0.6
  1588→- صعودی خفیف (سناریو ۴): 0.3
  1589→
  1590→P_Bearish_Weighted = Σ (P_Scenario_i × Severity_Factor_i) برای i = 6 تا 9
  1591→
  1592→Severity_Factor:
  1593→- شوک نزولی (سناریو ۹): 1.0 (بیشترین شدت)
  1594→- نزولی شتاب‌دار (سناریو ۸): 0.8
  1595→- نزولی قوی (سناریو ۷): 0.6
  1596→- نزولی خفیف (سناریو ۶): 0.3
  1597→```
  1598→
  1599→#### مثال محاسبه:
  1600→
  1601→```
  1602→P_Bullish_Cumulative = 0.08 + 0.15 + 0.28 + 0.12 = 0.63 (۶۳٪)
  1603→P_Neutral_Cumulative = 0.15 (۱۵٪)
  1604→P_Bearish_Cumulative = 0.08 + 0.08 + 0.04 + 0.02 = 0.22 (۲۲٪)
  1605→
  1606→جمع کل = 0.63 + 0.15 + 0.22 = 1.00 (۱۰۰٪) ✅
  1607→
  1608→P_Bullish_Weighted = (0.08 × 1.0) + (0.15 × 0.8) + (0.28 × 0.6) + (0.12 × 0.3)
  1609→                   = 0.08 + 0.12 + 0.168 + 0.036
  1610→                   = 0.404
  1611→
  1612→P_Bearish_Weighted = (0.02 × 1.0) + (0.04 × 0.8) + (0.08 × 0.6) + (0.08 × 0.3)
  1613→                   = 0.02 + 0.032 + 0.048 + 0.024
  1614→                   = 0.124
  1615→```
